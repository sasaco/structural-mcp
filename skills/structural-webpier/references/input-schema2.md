# 入力 `pre/input.json`（schema 2）の意味

項目の一覧・型・選択肢・単位・印字桁は `webpier_get_input_schema`（WebPier の項目表 `webpier/inputs/fields.py` から作る）が正。ここには意味と、資料から値を写すときの注意だけを書く。確かめた版：WebPier `b6c349c`（`webpier/inputs/parse.py`、入力エディタの図 `webpier/gui/assets/`、`README.md`・`CONTEXT.md`。コードで確認、2026-10-19）。

## 書き方の規則

- UTF-8（BOM なし）の JSON。`schema_version: 2`。**全部のキーが要る**（値が空欄でも `null` で書く）。知らないキーは入力エラー。
- **空欄は `null`、`0` は数値**。計算に要る値が `null` なら入力エラー（値を補わない）。資料から決まらない値は `null` のまま利用者に聞く。
- **印字桁に丸めた値を書く**（桁より細かい値は黙って丸めず入力エラー）。桁は schema の `x-webpier-digits`、単位は `x-webpier-unit`。おもな桁：寸法・水位・桁長・高さ・支承位置・層厚 m 3桁、D1・D2・雪荷重・軸重 kN 2桁、分担率・衝撃係数・荷重修正係数 3桁、摩擦係数 2桁、単位体積重量 kN/m³ 1桁、N値・qu・Ed・曲線半径・速度は整数、φd 1桁、コンクリート強度 N/mm² 1桁、鉄筋の位置・かぶり mm 1桁、径 mm 整数。
- 選択肢はプログラムが持つ（schema の `enum`）。一覧にない値は入力エラー。
- **派生値は入力しない**：排除した土の単位体積重量、B・C 支点の合計は WebPier が求めて印刷する。
- **空欄が 0 の値**：雪荷重（空欄は雪荷重なし。WebPier 決定62。B・C支点の支承に雪荷重が1つもなければ、0610 以降で雪荷重のケースを作らない。決定69）と支持層の `一軸圧縮強度_qu`（決定63）。ほかの空欄は入力エラー。
- `x-webpier-reserved`（杭・斜角・遠心の作用方向・梁の詳細位置）は予約項目で、形式と桁だけを確かめ、計算に使わない。
- `出典` は自由な形式で、計算に使わない。**どの資料のどのページから写したか、利用者に確かめた値はどれか**を書いておく。

## 節ごとの意味

### 下部構造（`下部構造`）

入力エディタの図（側面＝線路方向に見た図が B、正面＝線路直角方向に見た図が W）：

| 項目 | 意味 |
|---|---|
| `寸法.側面.B1` | はりの線路方向の幅（B1 > B4＋B5 が要る） |
| `B2`・`B3` | 桁受け（H1 > 0 のとき）の位置と幅 |
| `B4`・`B5` | はりのハンチの起点側・終点側の張出し（柱面から） |
| `B6` | 柱の線路方向の幅 |
| `B7`・`B8`・`B9` | フーチングの起点側の張出し・柱の下の幅・終点側の張出し |
| `寸法.正面.W1`〜`W9` | 同じ並びの線路直角方向（W4・W5 ははりの左右の張出し＝片持ち梁、W6 は柱の直角方向の幅、W7〜W9 はフーチング） |
| `寸法.高さ.H1`〜`H6` | H1 桁受け、H2 はり、H3 ハンチ、H4 柱（はり下からフーチング天端まで）、H5 フーチングのテーパー、H6 フーチングの厚さ |
| `土かぶり.起点側_df1`・`終点側_df2` | フーチング天端の上の土かぶり |
| `水位.高水位_hw1`・`平水位_hw2`・`低水位_hw3` | **基礎下面からの高さ**（地表からの深さではない） |
| `単位体積重量` | 梁・躯体、フーチング、上載土（`杭` は予約） |
| `杭種` | 「直接基礎」だけ計算できる |

### 上部構造（`上部構造`）

- `起点側`・`終点側`：桁ごとの `桁長.L1`・`スパン長`・`L2`（支点から桁端まで）、`衝撃係数_単線終局`、`曲線半径`、`列車速度`、`高さ.h1`〜`h4`（h1 は橋脚天端から桁下面まで、h1＋h2＋h3 がレール面の高さ、h4 はレール面から上の受風の高さ。列車ありの受風は max(車両の受風高, h4)。`webpier/calc/reaction/transverse.py`）、`重心高_hs`（地震時の桁の慣性力の作用高さ。橋脚天端から）、`支承位置_f`（橋脚の中心線から支承までの線路方向の距離）。
- `支承データ.起点側`・`終点側`：`支承名`（可動・固定）、`摩擦係数_μ`、`復旧性制動係数`（任意。空欄なら安全性の ρu×γB）、ゴム支承とストッパーの箇所数（0900 だけが使う）。
- `列車`：`車両名`（EA-17・P-16 など。制動・始動の規定が決まる）、1両の長さ、軸距、軸重（地震以外 kN、地震時 kN/m）、編成数、車両高、荷重修正係数。

### 上部工反力（`上部工反力`）

- 起点側の桁は A支点（遠い側。合計を入力）と B支点（この橋脚の上。支承ごと）、終点側の桁は C支点（この橋脚の上）と D支点（遠い側の合計）。
- B支点・C支点は**10枠の配列**で、使わない枠は**枠ごと `null`**（空き支承枠）。支承位置が入っている枠の空欄は入力エラー。
- 各支承：`支承位置`（**柱の中心線から**測った線路直角方向の距離。はりの中心からではない。符号で左右を区別）、D1・D2・雪荷重（2・10・30年確率。空欄は 0）、`列車分担.L1`・`L2`（その支承が受ける列車1・2の分担率。負もある）。L3・L4 は空欄（2線まで）。

### 地盤データ（`地盤データ.層`）

- 先頭は層番「表層」、層番「支持層」がちょうど1行。最大11行。地表から順に並べる。
- Df（H6＋H5＋min(df1, df2)）の範囲の層（WebPier 決定64）：支持層より上の層は `層厚` を入力し、支持層の Df 内の厚さは Df − Σ(上の層厚)。表層の `層厚` は空欄（キーなし）でもよく、そのときは Df から表層と支持層の間の層厚を引いた残りが表層で、支持層は基礎底面から。上の層厚の合計が Df を超えると入力エラー。支持層より下の行は計算に使わない。
- Df の範囲の層は湿潤・水中の単位体積重量が必要（γe2 は層ごとの水位より上・下の厚さで加重平均）。排除した土 γ′（0710・0720）は基礎底面からフーチング高さ H5＋H6 の範囲の層の湿潤の平均。
- 支持層の `内部摩擦角_φd` は 25 度以上 90 度未満、`変形係数_Ed` は正。表層の湿潤・水中の単位体積重量は必須。
- 0612・0622 の基礎の照査は支持層が砂質土・砂礫のときだけ。

### 鉄筋（`鉄筋.梁`・`鉄筋.柱`・`鉄筋.フーチング`）

- 全部のキーが要るが、値は空欄（`null`）で保存できる。値を要する段階でパス付きの入力エラーになる。`concrete_strength_mpa` は3部材とも必須。
- 柱：`main_rows`（面・段・片面本数・配置の方法）、`column_hoops`（帯鉄筋。方向ごとの有効本数・間隔）、`aggregate_max_mm`（柱のコンクリートの粗骨材最大寸法。0611・0621 と JRSNAP の入力の両方が使う）。`side_rows`・`band_rows` は柱では空の配列。`manual_basis` は詳細位置を使うときだけ。
- 梁（片持ち梁）・フーチングは 0900〜0910・0800〜0820 を作るときに実体が要る。WDJ で表せない配筋はパス付きの入力エラー。
- 配筋は入力エディタの鉄筋の画面で入れると、配置図で確かめながら書ける（SKILL.md「入力エディタ」）。

### 照査の条件

| 節 | 内容 | 要る段階 |
|---|---|---|
| `jrsnap_longitudinal`・`jrsnap_transverse` | 部材係数 γb（Vcd・Vsd・Vdd）、荷重増分の分割数、制限ステップ、目標変位の大きさ（向きは入れない） | 0710・0720 以降 |
| `耐震設計条件` | 地域別（A〜C地域）、地盤区分（G0〜G5。地盤データの土質区分とは別物）。橋脚に1組 | 0711・0721（0800〜0910） |
| `柱の断面照査` | 鋼材の腐食に対する環境条件（柱に1つ）、外観の照査、ε'csd、適用基準の機関、JR-001・JR-004 | 0611・0621（0810・0820・0910 も共用） |
| `片持ち梁の照査` | 上面・下面・側面の環境条件、外観の照査、疲労（列車本数・設計耐用年数・等価繰返し回数） | 0900・0910 |

- JRSNAP の部材係数 γb は説明書の標準値（1.3・1.1・1.2）と見本の値（2.0・1.3・1.8）が違う。どちらも補わないので、利用者に決めてもらう。
- 等価繰返し回数は外部プログラム N-EQUIVALENT の値を入れる。

## どの段階が使うか

| 段階 | 値が要るおもな節 |
|---|---|
| 0500 | 下部構造、地盤データ |
| 0600 | 下部構造、上部構造、上部工反力 |
| 0610・0620 | 上と同じ |
| 0611・0621 | ＋`鉄筋.柱`、`柱の断面照査` |
| 0612・0622 | 0610・0620 と同じ（支持層は砂質土・砂礫） |
| 0710・0720 | ＋`鉄筋.柱`、`jrsnap_*` |
| 0711・0721 | ＋`耐震設計条件` |
| 0800〜0820 | ＋`鉄筋.フーチング`、`柱の断面照査` |
| 0900・0910 | ＋`鉄筋.梁`、`片持ち梁の照査`、支承データの箇所数 |

- どの段階でも、入力の解析が必須の値（`杭種`、3部材の `concrete_strength_mpa`、地盤データの表層・支持層の必須項目、選択肢の項目など）は空欄にできない。
- 最終的には `webpier_validate` を作りたい選択で呼んで確かめる。

## 資料から写すとき

- 一般図（寸法・水位・土かぶり）、上部工の設計計算書（支点反力・桁の形状・支承）、地盤調査（層・N値・φ・Ed）、配筋図（鉄筋）、設計方針（車両・耐震設計条件・照査の条件）が出どころになる。
- 図の寸法の取り方が WebPier の定義（上の表）と違うときは読み替えを `出典` に書く。読み替えが一つに決まらないときは利用者に聞く。
- 見本（WebPier の repo の `pre/input.json`、Example橋脚2）は形の参考にだけ使い、値を持ち込まない。
