# 入力 `pre/input.json`（schema 2）の意味

項目の一覧・型・選択肢・単位・印字桁は `webpier_get_input_schema`（WebPier の項目表 `webpier/inputs/fields.py` から作る）が正。ここには意味と、資料から値を写すときの注意だけを書く。確かめた版：WebPier `b6c349c`（`webpier/inputs/parse.py`、入力エディタの図 `webpier/gui/assets/`、`README.md`・`CONTEXT.md`。コードで確認、2026-10-19）。

## 書き方の規則

- UTF-8（BOM なし）の JSON。`schema_version: 2`。**全部のキーが要る**（値が空欄でも `null` で書く）。知らないキーは入力エラー。
- **空欄は `null`、`0` は数値**。計算に要る値が `null` なら入力エラー（値を補わない）。資料から決まらない値は `null` のまま利用者に聞く。
- **印字桁に丸めた値を書く**（桁より細かい値は黙って丸めず入力エラー）。桁は schema の `x-webpier-digits`、単位は `x-webpier-unit`。おもな桁：寸法・水位・桁長・高さ・支承位置・層厚 m 3桁、D1・D2・雪荷重・軸重 kN 2桁、分担率・衝撃係数・荷重修正係数 3桁、摩擦係数 2桁、単位体積重量 kN/m³ 1桁、N値・c・Ed・曲線半径・速度は整数、φd 1桁、コンクリート強度 N/mm² 1桁、鉄筋の位置・かぶり mm 1桁、径 mm 整数。
- 選択肢はプログラムが持つ（schema の `enum`）。一覧にない値は入力エラー。
- **派生値は入力しない**：排除した土の単位体積重量、B・C 支点の合計は WebPier が求めて印刷する。
- **空欄が 0 の値**：雪荷重（空欄は雪荷重なし。WebPier 決定62。B・C支点の支承に雪荷重が1つもなければ、0610 以降で雪荷重のケースを作らない。決定69）と支持層の `粘着力_c`（決定63。決定84 で一軸圧縮強度 qu から c に替わった）。地盤の層の `De` の空欄は「その層は液状化しない」（1）。ほかの空欄は入力エラー。
- `x-webpier-reserved`（杭・斜角・遠心の作用方向・梁の詳細位置）は予約項目で、形式と桁だけを確かめ、計算に使わない。
- `出典` は自由な形式で、計算に使わない。**どの資料のどのページから写したか、利用者に確かめた値はどれか**を書いておく。

## 節ごとの意味

### 下部構造（`下部構造`）

入力エディタの図（側面＝線路方向に見た図が B、正面＝線路直角方向に見た図が W）：

| 項目 | 意味 |
|---|---|
| `寸法.側面.B1` | はりの線路方向の幅（B1 > B4＋B5 が要る） |
| `B2`・`B3` | 桁受け（H1 > 0 のとき）の位置と幅 |
| `B4`・`B5` | はりのハンチの起点側・終点側の張出し（柱面から） |
| `B6` | 柱の線路方向の幅 |
| `B7`・`B8`・`B9` | フーチングの起点側の張出し・柱の下の幅・終点側の張出し |
| `寸法.正面.W1`〜`W9` | 同じ並びの線路直角方向（W4・W5 ははりの左右の張出し＝片持ち梁、W6 は柱の直角方向の幅、W7〜W9 はフーチング） |
| `寸法.高さ.H1`〜`H6` | H1 桁受け、H2 はり、H3 ハンチ、H4 柱（はり下からフーチング天端まで）、H5 フーチングのテーパー、H6 フーチングの厚さ |
| `土かぶり.起点側_df1`・`終点側_df2` | フーチング天端の上の土かぶり |
| `水位.高水位_hw1`・`平水位_hw2`・`低水位_hw3` | **基礎下面からの高さ**（地表からの深さではない） |
| `単位体積重量` | 梁・躯体、フーチング、上載土 |
| `基礎形式` | 「直接基礎」「場所打ち杭」「鋼管ソイルセメント杭」。杭基礎は最上位の `杭基礎`（下）を使い、杭基礎で選べる出力項目は段ごとに広がる（いまはなし。選べない項目を `true` にすると `outputs.<項目>` が入力エラー。WebPier 決定84） |

### 上部構造（`上部構造`）

- `起点側`・`終点側`：桁ごとの `桁長.L1`・`スパン長`・`L2`（支点から桁端まで）、`衝撃係数_単線終局`、`曲線半径`、`列車速度`、`高さ.h1`〜`h4`（h1 は橋脚天端から桁下面まで、h1＋h2＋h3 がレール面の高さ、h4 はレール面から上の受風の高さ。列車ありの受風は max(車両の受風高, h4)。`webpier/calc/reaction/transverse.py`）、`重心高_hs`（地震時の桁の慣性力の作用高さ。橋脚天端から）、`支承位置_f`（橋脚の中心線から支承までの線路方向の距離）。
- `支承データ.起点側`・`終点側`：`支承名`（可動・固定）、`摩擦係数_μ`、`復旧性制動係数`（任意。空欄なら安全性の ρu×γB）、ゴム支承とストッパーの箇所数（0900 だけが使う）。
- `列車`：`車両名`（EA-17・P-16 など。制動・始動の規定が決まる）、1両の長さ、軸距、軸重（地震以外 kN、地震時 kN/m）、編成数、車両高、荷重修正係数。

### 上部工反力（`上部工反力`）

- 起点側の桁は A支点（遠い側。合計を入力）と B支点（この橋脚の上。支承ごと）、終点側の桁は C支点（この橋脚の上）と D支点（遠い側の合計）。
- B支点・C支点は**10枠の配列**で、使わない枠は**枠ごと `null`**（空き支承枠）。支承位置が入っている枠の空欄は入力エラー。
- 各支承：`支承位置`（**柱の中心線から**測った線路直角方向の距離。はりの中心からではない。符号で左右を区別）、D1・D2・雪荷重（2・10・30年確率。空欄は 0）、`列車分担.L1`・`L2`（その支承が受ける列車1・2の分担率。負もある）。L3・L4 は空欄（2線まで）。

### 地盤データ（`地盤データ.層`）

- 先頭は層番「表層」、層番「支持層」がちょうど1行。最大11行。地表から順に並べる。
- Df（H6＋H5＋min(df1, df2)）の範囲の層（WebPier 決定64）：支持層より上の層は `層厚` を入力し、支持層の Df 内の厚さは Df − Σ(上の層厚)。表層の `層厚` は空欄（キーなし）でもよく、そのときは Df から表層と支持層の間の層厚を引いた残りが表層で、支持層は基礎底面から。上の層厚の合計が Df を超えると入力エラー。支持層より下の行は計算に使わない。
- Df の範囲の層は湿潤・水中の単位体積重量が必要（γe2 は層ごとの水位より上・下の厚さで加重平均）。排除した土 γ′（0710・0720）は基礎底面からフーチング高さ H5＋H6 の範囲の層の湿潤の平均。
- 支持層の `内部摩擦角_φd` は 25 度以上 90 度未満、`変形係数_Ed` は正。表層の湿潤・水中の単位体積重量は必須。
- 0612・0622 の基礎の照査は支持層が砂質土・砂礫のときだけ。
- `粘着力_c`（kN/m²、整数）と `De`（0〜1、小数3桁。空欄は 1）が列にある（`一軸圧縮強度_qu` はない）。直接基礎で c を使うのは支持層の c＝0 の確認だけ。
- 杭基礎の層は、層番の約束（表層・支持層）を持たず40行まで。最後の層は下に続く。フーチング底面と杭先端で切って SOIL-JR の行にするのは 0500（杭基礎）の段階（ADR-0013）。

### 杭基礎（最上位の `杭基礎`、WebPier 決定80・84）

- `基礎形式` が杭基礎のときだけ使う（直接基礎では形式と桁だけを検査）。`杭長`（m）・`杭の単位体積重量`（kN/m³）、`場所打ち杭`（`杭径` m・`f'ck` N/mm²・`施工条件` 自然泥水／安定液使用）、`鋼管ソイルセメント杭`（`ソイルセメント径` m・`鋼管外径` m・`鋼管厚` mm〔腐食代を含む〕・`腐食代` mm・`鋼管材質` SKK400／SKK490〔杭体の照査に要る〕）、`配置`。選んだ基礎形式の項目だけが要る。
- `配置`：`形式`（格子／千鳥）、`線路方向の列の位置`・`線路直角方向の列の位置`（フーチングの中心からの符号付きの距離 m の配列。1〜99列、小さい順）、`抜く杭`（`線路方向の列`・`線路直角方向の列` の番号〔1から〕の配列）。千鳥は両方向とも奇数列で、番号の和が偶数の位置にだけ杭があり、杭のない位置は抜けない。どの列も杭が1本は残る。列ごとの本数・間隔・SOIL-JR の行は入力しない（導く）。

### 鉄筋（`鉄筋.version` 3：`鉄筋.梁`・`鉄筋.柱`・`鉄筋.フーチング`）

確かめた版：WebPier `1f5c8de`（`webpier/inputs/fields.py` の `_column`・`_beam`・`_footing`・`_rebar`、`webpier/inputs/rebar.py`、`tests/fixtures/inputs/current.json`、WebPier 決定68。コードで確認、2026-10-20）。

- `鉄筋.version` は 3。旧形式（version 2 の `main_rows`・`side_rows`・`band_rows`・`position_mode`・`manual_positions`・`manual_basis`・`stack_order`）は読み替えず、入力エラーになる。
- 全部のキーが要るが、値は空欄（`null`）で保存できる。値を要する段階でパス付きの入力エラーになる。`concrete_strength_mpa` は3部材とも必須。
- 共通（3部材とも）：材質は部材ごとの `materials.main`（主鉄筋・側面筋）と `materials.transverse`（帯鉄筋・スターラップ）だけ（SD295・SD345・SD390）。`pure_cover_mm`（純かぶり：コンクリート面から最も外側の鉄筋の外面まで）、`aggregate_max_mm`（粗骨材の最大寸法）。段の芯かぶりは `cover_mode`（自動・指定）と `center_mm`（指定のときの値）。自動の決め方は部材ごとに下に書く。2段目以降の芯かぶりは、同じ並びのひとつ前の段＋径＋あき。
- 柱：
  - `main_bars.{線路,直角}`：1段目の `diameter_mm`・`per_face_count`（片面本数）・`cover_mode`・`center_mm`、並べ方 `distribution`（`mode` は 等分・中央ピッチ・両端＋中央ピッチ、`edge_center_mm` は端の芯距離 e、`pitch_mm` は p）、`endpoints`（等分のとき e の位置に鉄筋を置くか：含む・含めない）。`inner_layers` は2段目以降の `per_face_count` と `clear_gap_mm`（前の段とのあき）だけで、径と並べ方は1段目と同じ。内側の段は1段目の位置のうち中央の本数分に置く。芯かぶりの自動＝純かぶり＋外側の帯鉄筋の径（`column_hoops.enclosing_diameter_mm`）＋径／2。
  - `table_overrides.{線路,直角}`：方向別の鉄筋配置表で変えた芯位置・径（`center_mm`・`diameter_mm`）を、元の芯位置・径（`source_center_mm`・`source_diameter_mm`。生成した鉄筋を引き当てる鍵）と一緒に持つ。元の鉄筋がない変更は使われず、警告になる。同じ元の鉄筋への変更が2つあるもの・中身のない変更は入力エラー。
  - `column_hoops`：`enclosing_diameter_mm` と、方向ごとの範囲の行 `direction_rows`（`direction`・`diameter_mm`・`effective_legs`・`pitch_mm`・`start_mm`・`end_mm`。開始・終了は柱の下端から）。
  - `aggregate_max_mm`（柱のコンクリートの粗骨材最大寸法）は 0611・0621 と JRSNAP の入力の両方が使う。
- 梁（0900・0910。柱前面の断面 B1 ×（H2＋H3））：
  - `faces.{上,下}`：1段目の `diameter_mm`・`count`（2本以上）・`cover_mode`・`center_mm` と、`inner_layers`（`count`・`clear_gap_mm`）。上面だけ形状 `bar_type`（ループ筋・直筋）があり、下面は常に直筋。下面の2段目以降は、エディタに出ないがデータと計算に残る。芯かぶりの自動＝純かぶり＋スターラップの径＋径／2。
  - 段の本数とあきは Capacita の段の割り方（総本数を1段目の本数で割る）に合わせる：最後の段を除いて1段目と同じ、最後の段は1段目以下、あきは一定。外れるとパス付きの入力エラー（例：[17, 8, 8] は Capacita が 17・16 と読む）。
  - `side_bars`：なしは `null`。`diameter_mm`・`per_face_count`（1つの面の本数）・`start_mm`（上面から1本目の芯まで）・`pitch_mm`・`stirrup_position`（スターラップの内側・外側）・`cover_mode`・`center_mm`。芯かぶりの自動＝純かぶり＋（内側なら）スターラップの径＋径／2。
  - `stirrups`：`diameter_mm`・`effective_legs`（効く脚の本数）・`pitch_mm`（間隔）。
- フーチング（0800〜0820）：
  - `faces.{上,下}`：`outer_direction`（その面で1段目が外側になる方向。線路・直角）と、方向ごとの1段目（`diameter_mm`・`pitch_mm`・`cover_mode`・`center_mm`）と `inner_layers`（`pitch_mm` と、同じ方向のひとつ前の段とのあき `clear_gap_mm`。径は1段目と同じ）。芯かぶりの自動＝外側の方向は純かぶり＋径／2、もう一方は純かぶり＋外側の方向の径＋径／2。
  - 0800〜0820 は下面だけを読む（上面は空欄でも計算できる。エディタは上面の `outer_direction` を出さないが、データに残す）。
  - 1 m 当たり本数は 1000／ピッチで、端数を許す（小数2桁。1000／130 ＝ 7.69）。下面の複数段は Capacita の段の割り方に合わせる（最後の段を除いて1段目と同じ本数、最後の段は1段目以下、あきは一定。外れるとパス付きの入力エラー）。
  - `stirrups.{線路,直角}`：`diameter_mm`・`pitch_mm`（張出しに沿う間隔）・`distribution_mode`（幅方向の指定：間隔・密度）・`width_pitch_mm`（間隔のとき）・`density_per_m`（密度のとき。幅 1 m 当たりの本数、小数1桁）。
- 梁（片持ち梁）・フーチングは 0900〜0910・0800〜0820 を作るときに実体が要る。WDJ で表せない配筋はパス付きの入力エラー。
- 警告（計算は止めない。入力エディタと「入力チェック」が示す）：柱の元の鉄筋のない配置表の変更、梁の鉄筋の重なり（芯の距離が2本の径の平均より近い）、フーチングの段の交差（同じ面で |c_a − c_b| ＜ (d_a ＋ d_b)/2）。
- 配筋は入力エディタの「05 鉄筋」で、部材ごとのカードに入れる。柱は「断面図・配置表」、梁とフーチングは「配筋略図」のウィンドウで確かめながら書ける（SKILL.md「入力エディタ」）。

### 照査の条件

| 節 | 内容 | 要る段階 |
|---|---|---|
| `jrsnap_longitudinal`・`jrsnap_transverse` | 部材係数 γb（Vcd・Vsd・Vdd）、荷重増分の分割数、制限ステップ、目標変位の大きさ（向きは入れない） | 0710・0720 以降 |
| `耐震設計条件` | 地域別（A〜C地域）、地盤区分（G0〜G5。地盤データの土質区分とは別物）、液状化指数（`5<PL<20`・`20<PL`。液状化する地層〔De が 1 未満〕がある杭基礎の 0711・0721 だけ要る。空欄でよい）。橋脚に1組 | 0711・0721（0800〜0910） |
| `柱の断面照査` | 水掛かりの程度（常時乾燥・乾湿繰返し・常時湿潤。柱に1つ、フーチングも使う）、外観の照査、ε'csd、適用基準の機関、JR-001・JR-004 | 0611・0621（0810・0820・0910 も共用） |
| `片持ち梁の照査` | 上面・下面・側面の水掛かりの程度、外観の照査、疲労（列車本数・設計耐用年数・等価繰返し回数） | 0900・0910（`外観の照査` は 0400 も） |

- JRSNAP の部材係数 γb は説明書の標準値（1.3・1.1・1.2）と見本の値（2.0・1.3・1.8）が違う。どちらも補わないので、利用者に決めてもらう。
- 等価繰返し回数は外部プログラム N-EQUIVALENT の値を入れる。

## どの段階が使うか

| 段階 | 値が要るおもな節 |
|---|---|
| 0400 | 下部構造、`鉄筋.柱`・`鉄筋.梁`・`鉄筋.フーチング`（上面を含む）、`片持ち梁の照査.外観の照査` |
| 0500 | 下部構造、地盤データ |
| 0600 | 下部構造、上部構造、上部工反力 |
| 0610・0620 | 上と同じ |
| 0611・0621 | ＋`鉄筋.柱`、`柱の断面照査` |
| 0612・0622 | 0610・0620 と同じ（支持層は砂質土・砂礫） |
| 0710・0720 | ＋`鉄筋.柱`、`jrsnap_*` |
| 0711・0721 | ＋`耐震設計条件` |
| 0800〜0820 | ＋`鉄筋.フーチング`、`柱の断面照査` |
| 0900・0910 | ＋`鉄筋.梁`、`片持ち梁の照査`、支承データの箇所数 |

- どの段階でも、入力の解析が必須の値（`基礎形式`、3部材の `concrete_strength_mpa`、地盤データの表層・支持層の必須項目、選択肢の項目など）は空欄にできない。
- 最終的には、作りたい出力項目を `outputs` に書いた入力で `webpier_validate` を呼んで確かめる。

### 出力項目（`outputs`）

作る計算書を決める13項目（WebPier の決定72・73）。すべて必須で、値は `true`／`false` だけ（`null` は不可）。項目と段階・使う項目は SKILL.md の「出力項目の選び方」。計算の条件ではないが入力の一部なので、変えると入力の SHA-256 も変わる。

## 資料から写すとき

- 一般図（寸法・水位・土かぶり）、上部工の設計計算書（支点反力・桁の形状・支承）、地盤調査（層・N値・φ・Ed）、配筋図（鉄筋）、設計方針（車両・耐震設計条件・照査の条件）が出どころになる。
- 図の寸法の取り方が WebPier の定義（上の表）と違うときは読み替えを `出典` に書く。読み替えが一つに決まらないときは利用者に聞く。
- 見本（WebPier の repo の `pre/input.json`、Example橋脚2）は形の参考にだけ使い、値を持ち込まない。
