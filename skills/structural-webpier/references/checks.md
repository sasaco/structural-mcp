# 照査の中身と結果の読み方

WebPier の README・CONTEXT.md と WebPier の開発用スキル（webpier-foundation・webpier-capacita・webpier-aggrese・webpier-footing・webpier-cantilever。2026-10-19 に foundation-check・footing-check・cantilever-check から改名）のうち、計算書を使う人に要る部分。確かめた版：WebPier `b6c349c`（2026-10-19）、照査の前提（0400）と RC標準 R5 への切替は `bb4a2cf`（2026-10-21）、0900・0910 片持ち梁は `a5fc308`（WebPier 決定125、2026-10-31）。式や定数を変えるのは WebPier の開発の作業（WebPier の repo）。

## 共通の考え方

- **印字桁で計算する**：計算書に印刷する値は内部でも印字桁に丸め、後続の計算はその値を使う。印刷物の数値だけで検算できる。見本（Excel の計算書）と末位が 0.01 程度違うのは、見本が丸めない中間値で計算しているため。
- **元 Excel の誤りは再現しない**。見本との差のうち設計上残しているものは WebPier の README の「Example2 との既知の差」。
- **実行の成否と判定は別**：`ok: true` で `engineeringStatus: not_ok` は普通にある。NG でも生成は止まらない。
- **判定を返すのは 0400・0612・0622 だけ**。Capacita（0611・0621・0810・0820・0910）と Aggre-SE（0711・0721）は判定を返さないので `not_evaluated`。OK/NG は差し込まれたページで読む。照査を実行したことを合格とみなさない。

## 0400 照査の前提（WebPier が判定する）

- 柱・梁・フーチング（上面を含む）の配筋と `片持ち梁の照査.外観の照査` が空欄なら入力エラー。

- **鋼管ソイルセメント杭**（WebPier 決定99、見本 Example橋脚4 II-18〜29、杭体設計の手引き H26）：4.5 杭の構造細目に (1) 鋼管杭（径 800〜1200、肉厚 9 mm・1%D 以上、有効肉厚 6 mm・1.25%D 以上、継手〔見本の文〕、杭先端部〔ずれ止めは鋼管径の表、貫入長 1.5D・余裕長 0.5Dsc・根入れ長 Dsc を設計値にする〕、一覧表）、(2) 杭とフーチングの結合部（アンカー鉄筋 SD345/SD390・D19〜D38、かぶり≧φ、あき≧40・4/3Dmax・1.5φ、ずれ止めとのあき≧15、pc 1〜6%、フーチング内の定着 ld01＝k1(0.7fsyd/f'cd＋11)φ −10φ ≧20φ ＋5φ を 50 mm 切上げ、中詰めコンクリート長 max(1.5D, 100＋l'd＋lh＋100) を 50 mm 切上げ、帯鉄筋、ずれ止め、一覧表）、(3) ソイルセメント（qu は解説表1.8-1 の値、公称径 Dsc−Dsp≧200）を置く。ずれ止めは SS400・JIS の平鋼（有効肉厚と 20 mm 以下で最大の標準厚さ、幅は 2t' 以上の最小の標準幅）・表1.10-1 の間隔・2 段（V-4 の照査で段数を決めるのは鋼管杭の地震時ができてから）。見本と合わない点：段数（2／3）、最下段のずれ止めは中詰め下端から測り lz0＝max(D/4, lz) と比べる、ld01 は k1 を印字桁で使う（1054／1053）。4.1 の杭の配筋図は杭頭の結合部（側面・断面）と杭先端部。

## 0612・0622 基礎の照査（WebPier が判定する）

- 設計応答値は骨組解析の `*_ピックアップ反力.csv` のうち、フーチング底面の中心のばね支点の反力（Vd＝−fy、Hd＝|fx|、Md＝|mz|。2桁に丸める）。荷重から組み立て直さない。
- 4列：長期支持（抽出ケース7、鉛直反力が最大）、短期支持（8、同）、安全性の鉛直力最大（6 の鉛直反力が最大）、安全性の曲げ最大（6 の |mz| 最大）。
- 鉛直支持：γi・γa・pd1／qd（長期・短期）、γi・γa・Vd／Rvd（安全性）。qd は「砂質土の場合」の式 qvd＝frγ・Iγ・βb・Be・γe1・Nγ＋frq・Iq・γe2・Df・(Nq−1)、qd＝qvd＋γe2・Df。支持層は砂質土・砂礫だけ（粘性土・互層は入力エラー）。
- 長期の qd の上限：砂質土 300＋γe2・Df、砂礫 500＋γe2・Df。Df は 0500 の有効根入れ深さ。γe2 は Df の範囲の層の加重平均で、長期が平水位、短期・安全性が高水位（水位は基礎下面から）。
- 回転：γi・γa・ex／制限値（長期 B/6、短期 B/4）、安全性は γi・γa・Md／Mmd（Mmd＝Vd・B/2・(1 − Vd／(qd・B・L))）。
- 水平支持：γi・Hd／Rhd（Rhd＝frs・Vd・tanφ、frs＝0.33、全列 γi＝1.0）。
- 地盤抵抗係数・γi・γa・回転の制限値は WebPier の定数。照査値と ＯＫ／ＮＧ を表に印刷し、結果 JSON の `result.engineering_status` が `ok`（すべて満足）か `not_ok`（1つでも NG）。
- 合力の作用位置がフーチングの外、鉛直力が上向き、反力が読めないときは生成が止まる。
- 見本（Example橋脚2）の Df 3.78 は地盤調査の表層厚で、WebPier は形状からの表層厚（4.70）を使う。見本と値が違うのはこのため。

## 0710・0720 地震時荷重・0711・0721 静的非線形解析と耐震性能照査

- 0710：8基本ケース・4組合せ（地震は起点側 ← の片方向）。0720：9基本ケース・上り線・下り線それぞれ4組合せの8組合せ（地震は → の片方向で、下り線の組合せは逆向 ←）。組合せは照査パターン（ρm, αf）＝(1.0, 1.0)・(1.2, 1.0)・(1.0, 2.0)・(1.2, 2.0) の順（決定76）。雪荷重がなければ CASE-4 雪荷重を作らず、後の CASE を詰める（7・8ケース。決定69）。柱下端に 0.010 m の微小部材を置く（JRSNAP の M-θ 部材）。計算書に JRSNAP のデータ確認図（非線形番号図・断面番号図・要素関連データ一覧表・断面詳細図・節点ばね分布図）と荷重図を差し込む。JRSNAP のページはヘッダーに印刷日が入るので日ごとにバイトが変わる。
- 0720 の制御節点と La：桁の節点はそれぞれの支承の座（桁受けに載る桁は桁受け天端、ほかははり天端）から h1+h2。制御節点は桁の水平力の大きい側の桁の節点、同じなら高い方（WebPier 決定81。決定65 の重み付けの高さは廃止）。柱の M-θ の破壊形態は La/d によらず曲げ（`S` なし）で JRSNAP に自動算定させ、La/d＜1.25（低せん断スパン部材）は入力エラー（決定114）。以前の決定66 は 1.25≦La/d＜2 の柱を「せん断」（`S`）にしていて、Aggre-SE が損傷レベルの限界を降伏に揃えていた。P7 の直角方向（La/d 1.70）の 0720・0721 は、決定114 の後に計算し直すまでこの誤りを含む。
- JRSNAP の節点番号は上から・同じ高さでは左から（JRSNAP 操作説明書 2.1.6、WebPier 決定67）。桁受け（H1＞0）がある橋脚で番号がこの順でないと、JRSNAP は読み込めても解析が破綻する（降伏震度 0.0 前後、1回目の変位増分で「第2トライアル回数制限値到達」）。0711・0721 の計算書で降伏震度が極端に小さいときは、まず LOG と NDU の番号を確かめる。
- 0711・0721：NDU を JRSNAP で静的非線形解析し（確認には「耐力と変形性能の自動算定」は初期のまま実行、「基礎照査機能」は「いいえ」と答える）、その結果を Aggre-SE で耐震性能照査する。**計算書は Aggre-SE の帳票そのもの**（見出しも節の番号も足さない）。判定（損傷レベル、基礎の安定）は帳票で読む。
- 判定を読むときの注意：設計総括表と安全率一覧表で L1 地震動の判定が食い違うことがある（P7橋脚の 0711、2026-10-20：Kh/Khy＝1.018 が総括表では NG、安全率一覧表では OK。原因は調べていない。スキル `structural-aggrese`）。両方の表を見て、食い違えば利用者に伝える。
- 耐震照査の条件は `耐震設計条件`（地域別・地盤区分、液状化する杭基礎は液状化指数）だけが入力で、ほか（スペクトルⅠ,Ⅱ両方、照査パターンごとの照査項目（①②全 Case、③ (1.0, 2.0) 以外、④ ρm 1.2、⑤なし、⑥ (1.0, 1.0)、⑦⑧⑨ αf 1.0）、損傷レベルの制限値など）は WebPier の定め。
- 既知の差：WebPier の NDU は JRSNAP の基礎照査のデータを持たないので、Aggre-SE は直接基礎の照査値を DB1 から求める。作用は見本と一致し、抵抗側（Rvd など）は違う。
