## 出力項目と、作るもの・呼ぶ runner

作る計算書は入力の `outputs` だけで決まる（ツール・CLI・runner の引数では選ばない）。項目を `true` にするときは、それが使う項目も `true` にする（SKILL.md の表）。選んだ項目の段階をすべて作り直し、選ばなかった項目の成果物は残す。

| `true` にする項目 | 作る計算書 | runner |
|---|---|---|
| `ground_model`・`reactions`・`longitudinal`・`transverse`・`longitudinal_seismic`・`transverse_seismic` | 0500・0600・0610・0620・0710・0720 | FEMPython・JRSNAP |
| `ground_model`・`reactions`・`longitudinal_seismic`・`transverse_seismic` | 0500・0600・0710・0720（決定78：0610・0620 なし） | JRSNAP |
| 上に `longitudinal_frame_analysis`・`transverse_frame_analysis` | 上に 0611・0612・0621・0622 | FEMPython・JRSNAP・Capacita |
| 上の6項目に `*_nonlinear_analysis` 2つと `cantilever` | 上の6段階に 0711・0721・0900・0910 | 4つすべて |
| 13項目すべて | 全18段階 | 4つすべて |
| `detailing` だけ | 0400 | なし（場所打ち杭は `ground_model` も選び JRSNAP が要る。鋼管ソイルセメント杭は `longitudinal_nonlinear_analysis`・`transverse_nonlinear_analysis` も選び、JRSNAP・Aggre-SE が要る） |
| `ground_model` だけ（`reactions` だけ） | 0500（0600） | なし |
| `ground_model`・`reactions`・`longitudinal` | 0500・0600・0610 | FEMPython |
| それに `longitudinal_frame_analysis` | 0500・0600・0610・0611・0612 | FEMPython・Capacita |

- 0611 と 0612（0621 と 0622）は1つの出力項目で、同じ FrameWeb 入力を解析するので、骨組解析は1回で、ピックアップのファイルは1組だけ。
- 0610・0620 の荷重図は FEMPython が、0710・0720 のデータ確認図と荷重図は JRSNAP が描いて計算書に差し込む。**地震時の項目（0710・0720）は JRSNAP の runner が要る**。JRSNAP がなければ地震時以外の項目だけを `true` にして作る。
- `webpier_get_contract` の `outputs[].runners` は、その項目を選ぶときに呼ぶ runner（使う項目の分も含む）。
- runner の名前：`fempython`（`STRUCTURAL_MCP_FEMPYTHON_RUNNER`）、`webdan2`＝Capacita（`STRUCTURAL_MCP_WEBDAN_RUNNER`）、`jrsnap`（`STRUCTURAL_MCP_JRSNAP_RUNNER`）、`aggrese`（`STRUCTURAL_MCP_AGGRESE_RUNNER`）。

## 杭基礎の 0710・0720（WebPier 決定93・122）

- 場所打ち杭と鋼管ソイルセメント杭（WebPier 決定122）。0500 で SOIL-JR が返す .sdc の地震時のばね（非線形の水平地盤反力係数、有効抵抗土圧、押し・引きの Kv と降伏・終局の耐力、杭先端）から、WebPier が杭の要素分割と節点ばねを求めて NDU に書く（JRSNAP_Input の「杭の分割＆ばね取り込み」と同じ規則）。
- 鋼管ソイルセメント杭（WebPier 決定122、見本 Example橋脚4 IV-8〜26）：杭頭に結合部の材端回転ばね（JRSNAP の鋼管杭接合部 501、M-θ、0.01 m）と中詰め部の剛域（合わせて 1.0D）、その下を鋼管杭（JRSNAP の鋼部材（円形）の適用種別 鋼管杭、M-φ。鋼管だけ、外径 D−2c・有効肉厚 t−c）。入力は `杭基礎.鋼管ソイルセメント杭`（`鋼管材質` と `結合部` の全項目が要る）。非線形特性は JRSNAP が自動算定する。0711・0721 は Aggre-SE の照査だけで、杭頭反力の最大値から定める最小鉄筋量（場所打ち杭の頁）はない。.sdc は格子・千鳥で杭列を並べない形（`全列`・`奇数列`／`偶数列`）も読む。
- 0720 は逆向の組合せ用に NDU が2つ（`線路直角方向.ndu`・`線路直角方向_逆向.ndu`）。逆向は押す向きが反対になり、.sdc の1列目（押しの前列）が入れ替わるため。0710 は NDU 1つ。
- 杭の断面の鉄筋（主筋・帯鉄筋・かぶり）は入力の `鉄筋.杭`。段落し（`鉄筋.杭.cutoff`）があっても NDU の杭は杭頭の断面のまま（段落しは Aggre-SE の ⑧ が照査する。WebPier 決定98）。.sdc の列の形が「N列目」「全列」「奇数列・偶数列」以外、杭先端の水平・回転ばね（βl≦2.5）、杭の f'ck が JRSNAP の範囲（18≦f'ck≦80）に入らない入力は、解析が止まる・入力エラーになる（f'ck 30 の例で本物の JRSNAP の解析が最後まで終わることを確かめた）。
- 地盤区分 G0〜G2 は慣性力だけ。計算書は直接基礎と同じ内容で、組合せ Case の表の「地盤抵抗TYPE」の列だけ杭基礎では出さない。杭のモデルは JRSNAP のデータ確認図に出る。
- 地盤区分 G3〜G5 の杭基礎は地盤変位（応答変位法）も考慮する（WebPier 決定97）。0710・0720 は **SoilStructure の runner**（`STRUCTURAL_MCP_SOILSTRUCTURE_RUNNER`）で表層地盤の固有周期 Tg と L1・L2（スペクトルⅡ）の地盤変位 f(z) を杭の節点の深さで求め、計算書の末尾に「10.5（11.5） 表層地盤の挙動」を足す。入力は地盤の層の `せん断弾性波速度_Vs`（最後の層を除く全層。最後の層の上面が基盤面）・湿潤の単位体積重量と `耐震設計条件.地域別`。0711・0721 は 2 回解析する：1 回目の Aggre-SE の総括表から ρm 1.0・αf 1.0 正向の Case の Teq・Kheq・最大応答震度を読み、補正係数 ν と Case（①〜④、L1・L2）を決め、Case ごとの地盤変位の NDU（`<方向>_応答変位法_L1-1.ndu` など。`…_JRSNAP/` フォルダーの中）を JRSNAP で解析し、全 Case で Aggre-SE が照査し直す。計算書は WebPier の「応答変位法による設計応答値の算定」の頁＋Aggre-SE の report.pdf（この頁の方眼Excel はない）。
- 液状化する地層（`地盤データ.層` の `De` が 1 未満）がある入力（WebPier 決定95、P6c）：0710・0720 は押す向きごとに液状化時用の NDU（`線路方向_液状化.ndu`、`線路直角方向_液状化.ndu`・`線路直角方向_液状化_逆向.ndu`）も書く（ばねは `杭基礎(液状化時用).sdc` の表、組合せは ρm 1.0・αf 1.0 の 1 つ。計算書は変わらない）。0711・0721 は液状化時用の NDU も解析し、Aggre-SE のプロジェクトに液状化時の Case（通常の Case のあとに順向、逆向〔0721〕。照査項目 ②③⑤⑦⑨）を足す。`耐震設計条件.液状化指数` が要り、空欄のまま 0711・0721 を選ぶと入力エラー。L1 地震動の液状化と、液状化時の応答変位法は未対応。
- 液状化時の Case の基礎の安定の限界値は Aggre-SE の規則どおり：液状化時用の `.sdr` から入るのは復旧性の分（行 10〜16）で、安全性（安定レベル3）は液状化時の欄が空なので通常の値になる。

## 杭基礎（場所打ち杭）の 0711・0721（WebPier 決定94、P6b）

- 0710・0720 の NDU を JRSNAP で解析し、Aggre-SE で耐震性能照査する。計算書は直接基礎と同じ Aggre-SE の report.pdf そのもの。JRSNAP の runner は NDU ごとに1回で、0721 は順向と逆向の2つの NDU の結果を同じフォルダー `post/線路直角方向_JRSNAP/` に置く（ファイル名は NDU の名前から始まる。両方が書く空の `解析実行Err.log` は1つにする）。Aggre-SE のプロジェクト `線路直角方向.xml` は1本で、順向の4 Case と逆向の4 Case を指す。
- Aggre-SE の照査は、柱と杭（断面ごとの部材）の損傷レベル・破壊形態・耐力と、**⑦基礎の安定**（杭基礎の照査：鉛直支持力・引抜き・水平変位・回転角を安定レベル1・2・3で）。制限値は 0500 の `.sdr` から Aggre-SE が読む（`post/杭基礎.sdr`。0711 は橋軸方向、0721 は直角方向の段）。⑧杭の段落しは `鉄筋.杭.cutoff` の主鉄筋が入力されているときだけ照査する（段落し後の鉄筋・長さ・余裕率と、WebPier が計算した杭頭定着長をプロジェクトに書き、Aggre-SE の杭の段落とし計算書を計算書の最後に付ける。段落しの項目が空欄なら入力エラー。WebPier 決定98）。
- 計算書は Aggre-SE の report.pdf の後に、WebPier の頁「杭頭反力の最大値から定める最小鉄筋量」（見本 0440 の 2.4 (1)。Pvmax は Aggre-SE のピックアップの復旧性L2 の杭頭の軸方向圧縮の最大を杭列の本数で割った値）を置く。結果 JSON の `result` は `minimum`（この照査）と `response`（応答変位法。なければ null）。
- 直接基礎のステップ表（`_Aggre-SE_直接基礎.csv`）は作らない。成果物は `post/線路方向_JRSNAP/`・`線路方向.xml`・`線路方向_Aggre-SE.pik`・`線路方向_Aggre-SE.xlsx`（0721 は線路直角方向）と付帯JSON。付帯JSONの `seismic_check.limits` に、制限値を読んだ `.sdr` の SHA256 と方向がある。
- 計算書の「杭基礎の照査」のページは Aggre-SE の判定（OK・NG）。WebPier は判定を持たない（`not_evaluated`）。
