## 選択と、作るもの・呼ぶ runner

| `stage`（スイッチ） | 作る計算書 | runner |
|---|---|---|
| `all` | 0500・0600・0610・0620・0710・0720 | FEMPython・JRSNAP |
| `all`＋frame | 上に 0611・0612・0621・0622 | FEMPython・JRSNAP・Capacita |
| `all`＋nonlinear | `all` に 0711・0721・0900・0910 | 4つすべて |
| `all`＋両方 | 全17段階 | 4つすべて |
| `0500`・`0600` | その段階だけ | なし |
| `0610`・`0620`・`0612`・`0622` | その段階だけ | FEMPython |
| `0611`・`0621` | その段階だけ | FEMPython・Capacita |
| `0710`・`0720` | その段階だけ | JRSNAP |
| `0711`・`0721` | その段階だけ | JRSNAP・Aggre-SE |
| `0800` | 0612・0622・0711・0721・0800 | FEMPython・JRSNAP・Aggre-SE |
| `0810`・`0820` | 0612・0622・0711・0721・0800 とその段階 | 4つすべて |
| `0900` | 0711・0721・0900 | JRSNAP・Aggre-SE |
| `0910` | 0711・0721・0900・0910 | JRSNAP・Aggre-SE・Capacita |

- 1つの段階を選ぶと、依存段階は内部で計算するだけで成果物を作らない。ただし runner を動かす・runner の結果で仕上げる依存段階（0612・0622・0711・0721・0800・0900）は一緒に作る（WebPier の決定60）。
- スイッチは `stage: "all"` とだけ使う。選択式の段階は `stage` で直接選べばスイッチは要らない。
- 0611 と 0612（0621 と 0622）は同じ FrameWeb 入力を解析するので、両方を選んだ生成では骨組解析は1回で、ピックアップのファイルは1組だけ。
- 0610・0620 の荷重図は FEMPython が、0710・0720 のデータ確認図と荷重図は JRSNAP が描いて計算書に差し込む。**0710・0720 を含む生成（`all` を含む）は JRSNAP の runner が要る**。JRSNAP がなければ 0500・0600・0610〜0622 は段階ごとに選んで作る。
- runner の名前：`fempython`（`STRUCTURAL_MCP_FEMPYTHON_RUNNER`）、`webdan2`＝Capacita（`STRUCTURAL_MCP_WEBDAN_RUNNER`）、`jrsnap`（`STRUCTURAL_MCP_JRSNAP_RUNNER`）、`aggrese`（`STRUCTURAL_MCP_AGGRESE_RUNNER`）。
