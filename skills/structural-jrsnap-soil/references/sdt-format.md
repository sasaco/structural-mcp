## 0. ファイル全体の約束

- 書出しは VB の `FileOpen(OpenMode.Output)` と `PrintLine` を使う。文字コードはシステムの ANSI（日本語 Windows では CP932）、改行は CRLF で、最後の行にも CRLF が付く。[C][S]（E のサンプルは 1613 バイト、CRLF が 67 個）
- 数値には2つの書き方がある。
  - **文字列の項目**（`$"{a},{b},…"`、カンマ区切りの行）は `Conversions.ToString(double)` で書くので、`19`、`0.785398`、`-123456789.123457` のようになる。前後に空白は付かない。[C]
  - **数値を `PrintLine` に直接渡す行**（`B_N`、`B_Kind`、`K_FLG`、`NDEL` など値が1つの行）は VB の数値の印字規則で、正の数は前に空白1つ、後ろに空白1つが付く（` 5 `、` 1 `）。負の数は `-1 ` になる。[C][S]
  - `PrintLine(n, a, b)` のように2つ渡すと、14 桁ごとの印字ゾーンに分かれる。` 0             0 `（17文字）は、` 0 ` を 14 文字まで空白で埋めてから ` 0 ` を続けたもの。[C][S]
- 読込は VB の `Input #`（カンマか改行で区切る）と `LineInput` を使う。区切りは行の境目に依存しないが、書出しと同じ行構成にしておくのがよい。読込は値を読む順番だけで決まる。[C]
- **未入力の目印**：実数は `-123456789.123457`（`DBL_EMP`）、整数（short）は `-12345`（`INT_EMP`）。[C]
- **画面での丸め**：読み込んだ値はいったん画面の欄に入り、計算はその欄の文字を `Val()` で読み直した値を使う（`MDIfrmMain` の計算実行は `GetKihonData/GetKuiData/GetJibanData/GetKuiHaitiData` を通る）。そのため、欄の表示桁より細かい値は黙って丸められる。長さは 0.000、Es・Ec・t1・t2・腐食代・γ・B_N は 0.0、A・I は 0.000000、地層の層厚は 0.000、C・φ・γ・γ' は 0.0、N・Ex・Ed は整数、ρgE は 0.00、qsuk の直接入力値は 0.00。[C]（`Set*Data` の `Format`、セルの `NumberCellType.DecimalPlaces`）
- 1行目の版の読み方：`Ver.<Major>.<Minor>.<Build>.T08`。読込側は `.` で分けて、版の番号（≥ 5.3.1 か）と書式の番号（`T08` の最後の数字）で読む項目を切り替える。書式番号が 3 未満だと F_TEIKO がなく、4 以上で B_N、5 以上で S_rfkKind、6 以上で杭条件1行目が16項目、7 以上で地層が13項目と qtkDat、8 以上で ●地盤抵抗係数 の段がある。版が 5.3.1 以上で B_KuiType・B_JibanChosa があり、地盤抵抗係数は6行の形式になる。1.1.5 以上で液状化の段、1.1.6 以上で LiJudge 連携の段がある。**新しく書くときは `Ver.5.3.1.T08` で書き、下の構成をそのまま出す。**[C]

## 9. 検査の要点（`Check.cs`）

止まる検査（メッセージを出して計算しない）：
- 本数が空欄、本数が2以上なのに間隔が空欄、杭種や工法を選んでいない、杭先端や施工条件が有効なのに選んでいない
- 杭長・突出長・根入れ・平水位が空欄。有効な Es, Ec, D1, D2, t1, t2, 腐食代が空欄。A, I, 杭の単位体積重量が空欄
- 範囲：本数 1〜99、間隔・杭長・D1・D2 0.001〜99.999、突出長・平水位 ±99.999、根入れ 0〜99.999、Es・Ec・t1・t2・γ 0.1〜999.9、腐食代 0〜999.9、回転杭の D3 0.001〜99.999、n 0.1〜99.9
- 前面抵抗を考慮するとき：フーチングの5項目、埋戻し土の3項目（取り扱いが 0 か 2 のとき）
- 地盤：§4.1 の空欄とゼロの規則、層厚の合計 = 杭長 − 突出長、杭先端の行の規則
- 杭の配置：両方向の本数の合計の一致、各行の本数の範囲、千鳥配置で削除する位置の誤り、千鳥配置で列数が偶数（格子配置に戻される）
- 地盤抵抗係数の画面：値の欠け、0 < 降伏 ≦ 終局 ≦ 10

警告だけで続く：杭種ごとの D1 の適用範囲（「基礎標準に記載する杭種の杭径が適用範囲から外れているため、注意が必要です」）。n が空欄のとき（OK で n=1）。計算中の短い杭（l/D<10、βl<2.5）の確認（OK/キャンセル）、杭間隔係数 d<2、10本以上で d<3。

計算中に止まるもの（`Rcode`）：杭先端の地盤ばねの第2勾配が負（−4）、先端が粘性土で工法の適用範囲外（−3）、深礎杭の吹付けで水位と地層境界が一致しない（−2）、層の周面ばねの第2勾配が負。

## 10. 帳票と出力

- **計算の流れ**（`MDIfrmMain` の Index 8）：`Check.DataCheck` と `ControlChk` → 画面の欄から変数に読み直す → 必要なら地盤抵抗係数を既定値に戻す → `Calc.ResultFile` が中間結果を全部 `%TEMP%\Rtri\Output.tmp`（テキスト）に書く → `Output.ResultFile_Read` → 「計算が終了しました。連携ファイルを作成しますか？」→ 保存の画面で `.sdr`（`OutPut_Shousa`）と、同じ名前の `.sdc`（`OutPut_Renkei`）を書く。液状化を考慮するときは `(液状化時用).sdr` と `.sdcl` も書く。[C]
- **帳票**：「印刷プレビュー」で frmOutPutSelect（出力選択）を開いてから ComponentOne の `C1PrintDocument`（A4 縦）を組み、frmOutPut（印刷・プレビュー）に出す。「印刷」はすべての項目を選んだ状態で `PrintDialog()` を呼び、プリンターに送る。[C]
  - 選べる項目：表紙、入力データリスト（フーチング形状／杭条件／地盤条件）、計算結果：地盤反力係数の算定（杭先端の鉛直・せん断地盤反力係数、杭周面のせん断地盤反力係数、水平地盤反力係数、フーチング前面の水平地盤反力係数）、1/βの検討、地盤ばね定数の算定（杭先端のばね定数、杭周面のせん断ばね定数、杭周面の水平ばね定数、フーチング前面の水平ばね定数）、設計鉛直支持力および設計引き抜き抵抗力（押込み・引抜き）、水平変位および回転角の設計限界値、有効抵抗土圧力（単杭、群杭、群杭（応答変位法）、フーチング前面の水平支持力、有効抵抗土圧力図(単杭)）、解析用地盤ばね値総括表。ほかに一括出力と項目別出力の切替え、ヘッダー（バージョン／日付／ファイル名／タイトル）。フーチングがないか前面抵抗を考慮しないときは、フーチングの項目が外れる。[C]
  - ファイルへの出力：プレビューの「保存」（`C1PreviewActionFlags.FileSave`）だけ。出力形式の設定には C1d/C1dx/C1db/C1mdx、HTML、XPS、RTF、Text、Metafile、Excel、OpenXml（xlsx）がある。PDF は C1 の既定の出力に入っているはずだが、設定の一覧にはない [I]。帳票を直接ファイルに書く処理はない。[C]
- **画面なしで動かせるか**：コマンドライン引数を受け取らない（`Interaction.Command` などがない）。`Calc.ResultFile` と、連携ファイルを書く `Output.OutPut_Shousa/Renkei(_De)` は、グローバル変数だけを使う静的メソッドで、フォームには触らない（ただし `MsgBox` の警告がある）。一方、計算の前処理（m・n・Lm・Ln・Ed・地盤抵抗係数の既定値、`DataCheck`）は画面の欄から値を取る。`Output.Preview` は `frmOutPut.C1PrintDocument1` を使う。したがって、画面を出さずに動かすには、S_DataCheck のときのように別のアプリケーションドメインで画面を隠して操る仕組み（スキル structural-jrsnap-figures の ReportHost）か、リフレクションで前処理を再現する必要がある [I]（未実施）。今の確実な方法は、SKILL.md の「自動実行」（画面の自動操作）。
