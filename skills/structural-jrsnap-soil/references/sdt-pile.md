# .sdt の杭条件を書き換えて見本を作る

SOIL-JR の入力 .sdt（Shift-JIS・CRLF）の `●杭条件●` の段の意味。既存の .sdt を行単位で書き換え、SOIL-JR で計算させて、形の違う .sdr を作るときに使う。

根拠：SOIL-JR のソース（開発機のみ。インストール先の `SOIL-JR\Common.cs` の .sdt の書出し 1250 行〜と読込 1650 行〜、`frmInputData.cs` の杭種・工法の一覧と入力欄の名前、`CalcSub.cs` の断面積・断面二次モーメント、`Check.cs` の入力の検査）。コードで確認し、書き換えた .sdt を Ver.5.3-L01体験版2 で計算できた（2026-10-23）。作った見本は Batch の `tests/JRSNAP_Ver5.3-L01体験版2/08_基礎照査連携(V53)/`（README に変えた行）。

## 書き換え方

- バイト列を CP932 で文字列にし、**行全体を前後の改行ごと1回だけ置き換えて**から CP932 に戻す（往復で同じバイトになることを先に確かめる）。PowerShell 5.1 でスクリプトに日本語を書くときは、スクリプト自体を BOM 付き UTF-8 にする（BOM がないと ANSI として読まれて文字が化ける）。
- 3行目が表題（.sdr の2行目に出る）。見本を見分けられるように変えておくとよい。
- 書き換えた値が設計として妥当かは別の話。形を作るための値であることを見本の README に書く。

## `●杭条件●` の段

1行目（16項目）：

| 位置 | 項目 | 値 |
|---|---|---|
| 0 | `K_HAITI` 杭配置 | 1・2（画面の配置の選択） |
| 1・2 | 橋軸・直角の杭本数 | |
| 3・4 | 橋軸・直角の杭間隔 | |
| 5〜8 | `K_LM`・`K_LN` | |
| 9 | `K_KIND` 杭種 | 1 鉄筋コンクリート杭（場所打ち）、2 RC杭、3 PHC杭、4 SC杭、5 鋼管杭（画面の一覧の順＋1） |
| 10 | `K_KOHO` 工法 | 杭種1：1 場所打ち杭、2 先端強化型場所打ち杭。杭種2〜5：3 打込み杭、4 中掘り根固め杭、5 プレボーリング根固め杭、6 回転杭（鋼管杭のみ）、7 鋼管ソイルセメント杭（鋼管杭のみ） |
| 11 | `K_HKATAHOKO` | 杭種6 のときだけ |
| 12 | `K_SENTAN` 先端 | 杭種5・6 で工法3（打込み）のときだけ。1 先端開放鋼管杭、2 先端閉塞杭 |
| 13 | `K_SJYOUKEN` 施工条件 | 杭種1 で工法1・8 なら一覧＋1、工法2 なら一覧＋3。それ以外は 0（読込で画面の選択に使うので、ほかの杭種で 1 以上を入れない） |
| 14・15 | 深礎のオプション | |

2行目（14項目）：杭長、突出長、根入れ、水位、Es、Ec、D1、D2、t1、t2、腐食代、A、I、単位体積重量。未入力は `-123456789.123457`。D1・D2 は m、t1・腐食代は mm。

- 回転杭（杭種5・工法6）の入力欄は D1＝鋼管外径（0.4〜1.6m）、D2＝羽根外径、t1＝鋼管厚、t2＝**羽根内径 D3**（m、読込では `0.000` で表示）。t2 が 0 以下だと計算できない。
- A・I は画面が `CalcSub` の式で計算して入れる。回転杭は `A = π/4·{(D1−2c/1000)² − (D1−2t1/1000)²}`、`I = π/64·{(D1−2c/1000)⁴ − (D1−2t1/1000)⁴}`（c＝腐食代）。

例（PHC の見本の RC 杭を回転杭にした行）：

```
1,3,3,3,3,3,3,3,3,5,6,0,0,0,0,0
19,0,1,0.5,200,-123456789.123457,0.8,1.6,16,0.4,1,0.036898,0.002829,77
```

## 杭の配置

```
 1                ← K_FLG（書出し時の値。計算時に SOIL-JR が決め直す）
橋軸方向
3,0               ← 本数,1列目からの距離 を列の数だけ
2,3
3,6
直角方向
…
（空行）
 1                ← 抜く杭の数
2,2               ← 抜く杭の位置（橋軸の列, 直角の列）
（空行）
```

中抜きをやめるときは、抜く杭の数を ` 0 ` にしてその行を消し、各列の本数を全部にする。
