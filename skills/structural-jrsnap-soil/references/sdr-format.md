# 基礎照査連携データ（.sdr）の書式

SOIL-JR が計算のあと「連携ファイルを作成しますか？」で「はい」としたときに書く、基礎照査用のファイル。Aggre-SE（Batch）の基礎の照査条件の画面が「SOIL-JR結果ファイル(*.sdr)」として取り込む（structural-aggrese スキル）。解析連携用の `.sdc` とは別のファイル。

根拠：SOIL-JR のソース（開発機のみ。インストール先の `SOIL-JR\Output.cs` の `OutPut_Shousa`（通常時）と `OutPut_Shousa_De`（液状化時用）、`MDIfrmMain.cs` の計算後の処理、`frmIkkatu.cs`）。コードで確認し、Ver.5.3-L01体験版2 の SOIL-JR で出した .sdr と見比べた（2026-10-23）。

## ファイル

- Shift-JIS・CRLF。カンマ区切りで、数値の前に空白が1つ入る（`安定レベル2, 3141.6, …`）。
- 通常時は `<名前>.sdr`。液状化の判定をした計算（`J_LiJudgeFlg=1`）では、続けて `<名前>(液状化時用).sdr` も書く（解析連携用は `.sdc` と `(液状化時用).sdcl`）。**液状化時用だと分かる行は中身にない**。違うのは値と、安定レベル3 の水平変位の指標（`10.0%L≦9999mm`）だけ。
- 一括の連携（`frmIkkatu`）は通常時の .sdr と .sdc だけを書く。
- 同じ .sdt から出し直すと、.sdr はバイトまで同じになる（置き場所が違っても同じ。実アプリで3回確認、2026-10-23）。

## 並び（Ver.5.3）

```
Ver.5.3.1                                   1行目：SOIL-JR の版（Major.Minor.Build）
<表題>                                       2行目：.sdt の3行目（利用者が自由に書く）
フーチング有無,杭種,杭長,杭径,橋軸杭本数,直角杭本数,橋軸杭間隔,直角杭間隔,換算抵抗幅算定用杭本数
1, 1, 19, 1.000, 3, 3, 3, 3, 8              片方向が1本のときは、その方向の杭間隔に 0
(1)橋軸方向
【杭配置情報】                                K_FLG=1 のときだけ（下）
番号,1列目からの距離,杭本数
…
（空行）
【設計鉛直支持力の算定】  見出し行＋6行
【設計引き抜き抵抗力の算定】  見出し行＋6行
【水平変位の照査】  見出し行＋6行
【回転角の照査】  見出し行＋6行
(2)直角方向
（同じ並び）
```

各段の6行の性能項目は `安定レベル1(長期)`・`安定レベル1(短期)`・`安定レベル1(地震時以外)`・`安定レベル1(地震時)`・`安定レベル2`・`安定レベル3`。

| 段 | 列（0 始まり） |
|---|---|
| 設計鉛直支持力 | 0 性能項目、1 Rbuk、2 ΣRsuk、3 Ruk、4 Pb、5 γgr、6 **Rvd**、7 地盤抵抗係数フラグ |
| 設計引き抜き抵抗力（6列） | 0 性能項目、1 ΣRsuk、2 Wp、3 γgr、4 **Rtd**、5 フラグ |
| 設計引き抜き抵抗力（7列、工法コード 6＝回転杭） | 0 性能項目、1 **基準先端引抜き抵抗力Rtuk**、2 ΣRsuk、3 Wp、4 γgr、5 **Rtd**、6 フラグ |
| 水平変位 | 0 性能項目、1 **δL**、2 指標（`2.0%L≦100mm` など）、3 抵抗幅 |
| 回転角 | 0 性能項目、1 **θL** |

- 引抜きの 安定レベル2・3 の行は `0` を並べたもの（6列なら `0, 0, 0, 0, 0`、7列なら6つ）。
- `【杭配置情報】` の段は `K_FLG=1` のときだけ出る。SOIL-JR は計算時に、杭間隔が等しく、杭が全部（`K_HAITI=1` で 橋軸本数×直角本数）あるときに `K_FLG=0` にする（`Check.cs` 637 行）。中抜きのある 3×3 の見本では出て、9本全部にすると出ない（実アプリで確認）。
- **Aggre-SE が読む値（Rvd・Rtd・δL・θL）は両方向で同じになる**。水平変位の設計限界値は杭径と換算抵抗幅算定用杭本数だけで決まる（`Calc.cs: Get水平変位設計限界値`）。6列×2列で杭間隔も違う RC ラーメンのサンプルでも、違ったのは杭配置情報だけだった（実アプリで確認）。方向で値が違う .sdr を出させる入力は見つけていない。

## Ver.5.2 の書式（Ver.5.2.2 の見本で確認）

- 1行目の列に `換算抵抗幅算定用杭本数` がない。
- 方向ごとに「地震時以外」と「地震時」（液状化時用は「液状化時」と思われる。見本がない）の2つの段がある。
- 「地震時以外」の段の性能項目は5行：`長期支持性能`・`短期支持性能`・`安定(地震時以外)`・`残留鉛直変位(L1)`・`残留鉛直変位(L2)`。見出しの記号も違う（`Rtk`・`ΣRfk`・`Rk`・`Pt`・`fr`。引抜きの見出しは `設計引き抜き抵抗力vd(kN)`）。
- 「地震時」の段は、項目名のない数値行が1行ずつ（鉛直支持力は `先端地盤修正係数frt,…` の見出しの次の行の列6、水平変位・回転角は `設計限界値δL(mm)…`・`設計限界値θL(mm)` の見出しの次の行の列0）。
- 見本の同じ橋脚では、Ver.5.2 の 残留鉛直変位(L1)・(L2)・「地震時」と Ver.5.3 の 安定レベル1(地震時)・2・3 の回転角が 10・20・30、水平変位が 56.569・226.274・282.843 で並ぶ。マニュアルの比較では「旧 L1 を新レベル1へ機械的に対応付けるのは不適切」という記述もあり、対応は確かめていない（Batch の docs/issues/0012）。

Ver.5.2-L03 の SOIL-JR.exe も `C:\RTRI_Program\JRSNAP(Ver5.2-L03)` などにあるが、このスキルのスクリプトでは試していない（起動のライセンス引数の版が違う可能性がある）。
