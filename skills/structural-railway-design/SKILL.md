# 鉄道土木構造物の設計の知見

鉄道の RC 地下構造物（開削トンネル・ボックスカルバート・立坑・ピット・擁壁など）を設計計算するときの、**エンジンに依らない**知見を集める。
計算の道具は別のスキル：骨組解析は FEMPython、断面照査は `structural-capacita`、橋脚は `structural-webpier`、耐震の非線形解析は `structural-jrsnap-*`・`structural-aggrese`。

- 書いてあることは、基準・見本・発注者の設計条件で**読んで確かめたもの**か、案件で**採用した判断**（その旨と日付）。条番号のないことは推定と書く。
- 見本の計算書の数値（荷重・配筋・照査値）は別の構造物のもの。体裁・章立て・式の手本で、設計値として流用しない。
- 案件の条件（寸法・地盤・水位・作用係数の表）はその案件の設計条件が正。ここの値は例で、案件の資料で必ず確かめる。

## 基準の略称（計算書でもこの書き方で引く）

| 略称 | 基準 | よく引く条 |
|---|---|---|
| 【RC標準】 | 鉄道構造物等設計標準・同解説（コンクリート構造物）令和5年（R5）。前の版は平成16年（H16） | 7.2 安全性（破壊）の曲げ、9.2 復旧性（損傷）、解説表7.6.1 収縮・クリープの ε'csd |
| 【開削標準】 | 鉄道構造物等設計標準・同解説（開削トンネル） | 第Ⅱ編 5.4.2 路面交通荷重（解説表5.4.2-1）、5.4.3 地表面上の変動作用、5.4.6・5.4.7 永久作用としての側圧（5.4.6 に静止土圧係数の表）、7.2 剛域 |
| 【杭体手引き】 | 鉄道構造物等設計標準・同解説 基礎構造物（平成24年版）杭体設計の手引き | 1.3 場所打ち杭のコンクリート（表1.3-1 施工修正係数 ρc） |
| 【ボックス手引】・【開削マニュアル】 | 見本の計算書が引く手引き・マニュアル（正式名は見本の引用で確かめる） | 【開削マニュアル】7.4.3 せん断ひび割れ（耐久性） |

R5 と H16 では要求性能の行の名前と、Capacita の行・メッセージのコードが違う（`structural-capacita`）。
H16 系の見本や設計条件のフローが「復旧性（損傷）」（地震時以外）と書く照査は、R5 では**使用性（損傷）**に当たる（`references/frame-and-checks.md` の「R5 の要求性能の名前」）。

## 作用の記号（開削構造物の設計条件・見本で使う名前）

| 記号 | 作用 | 種別 |
|---|---|---|
| D1・D2 | 死荷重（D1 固定：躯体の自重、D2 付加：上家・設備・建築仕上げ） | 永久 |
| EHP・WHP | 永久作用としての側圧（土圧・水圧） | 永久 |
| Wp（Wp1 平水位・Wp2 低水位・Wp3 高水位） | 揚圧力 | 永久 |
| GLH | 地表面上の変動作用による土圧 | 変動 |
| L | 見本では路面荷重（上載荷重 10kN/m²）に使う例がある | — |

設計条件の作用係数の表には、ほかに EDV・EDH・EL・GD・L・I の行がある（意味は表の凡例で確かめる。鉛直・水平の土圧、列車荷重・衝撃などと推定）。

## 計算の進め方と、ユーザーに決めてもらうこと

1. **構造の条件**：寸法は図面（DXF の構造のレイヤ）で測った値を正とし、出典を入力に残す。計算の天端（GL か躯体の天端か）、隣接構造が接する面（土が無い面）、開口の位置。
2. **作用**：`references/loads.md`（側圧・上載荷重・GLH・水位・揚圧力・死荷重）。
3. **骨組と照査断面**：`references/frame-and-checks.md`（計算点、剛域、照査断面、支持条件、載荷パターン、組合せ、耐久性（永久作用）、水掛かり、かぶり）。
4. **照査の前提（構造細目）と配筋図**：`references/detailing.md`（断面力によらない細目の一覧と見本の条、中間帯鉄筋の置き方、ezdxf の配筋図）。
5. **底版**：`references/slab.md`（地盤反力度と揚圧力、四辺固定スラブの近似解法、符号）。
6. **計算書**：`references/reports.md`（章立て、印字桁と丸め、資料の読み方、照査結果の比べ方）。
7. **耐震の静的非線形解析**（橋脚など）：`references/seismic-nonlinear.md`（材料修正係数 ρm・基礎の支持力修正係数 αf の意味、照査パターンと正向・逆向、Case ごとの照査項目、基礎の設計応答値を採る Case）。
8. **場所打ち杭のコンクリート**：`references/piles.md`（【杭体手引き】表1.3-1 の施工修正係数 ρc と Vcd の低減係数、区分 A〜D の選び方、既設の杭で工法が分からないとき）。

次のことは設計者・発注者の判断。資料で答えが出なければ**推測で決めず**、推奨を付けて1問ずつ聞き、決まったら案件の決定の記録に書く。

- 地表面の荷重（上載荷重・路面交通荷重）を EHP に入れるか、GLH として変動作用にするか、両方か（両方なら二重に数えることを承知のうえと記録する）。
- 地震時土圧（応答変位法など）を考えるか。
- 水位（高水位・平水位・低水位）の標高と、浮上りの検討だけ高水位を設計GL にするか。
- 上家（地上の建屋）の反力を合計で与えるか支点ごとか、設備荷重（EV など）を入れるか。
- 載荷パターン（全方向・3方向・2方向。隣接構造で土の無い面）。
- 配筋が決まっていないときの仮定の配筋（仮定であることを計算書の外に記録する）。
- 見本・設計条件の「復旧性（損傷）」を R5 の使用性（損傷）として照査するか（安全係数の行が変わる）。外観のひび割れをどの面で照査するか。最小鉄筋量をどの断面力で照査するか。H16 の環境条件を R5 の水掛かりの程度にどう読み替えるか（`references/frame-and-checks.md`）。
- 静的非線形解析の照査パターン（ρm・αf の組）と逆向で解析する組合せ、Case ごとの照査項目、基礎・部材の設計応答値を採る Case（`references/seismic-nonlinear.md`）。

## 知見を足すとき

- 鉄道土木の設計に一般に通じること（条番号・式・表・資料の読み方・判断の選択肢）：このスキル（structural-mcp の `skills/structural-railway-design/`）を編集し、structural-mcp で commit する。
- 案件の値と判断そのもの（その構造物の寸法・採用した係数・発注者とのやり取り）：その案件の repo。ここには「こういう判断があり、こう決めた例がある（年月日）」の形でだけ書く。
- エンジンの性質：そのエンジンのスキル。
- 条番号は資料で確かめたものだけを書き、確かめた資料（基準の条、見本の頁、設計条件の節）を添える。覚えで書かない。
