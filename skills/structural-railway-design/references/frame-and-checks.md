# 骨組・組合せ・照査の前提

## 立坑・ピットの側壁を水平断面の骨組で解く

- 深さ方向に **1.0 m の帯**を切り出し、その深さの側圧を部材荷重（側圧 × 1.0 m、kN/m）として各面に一様に載せる。主鉄筋は水平筋。
- **計算点**は側圧が最も大きいか骨組が変わる深さ：底版上面（最も深い、四辺閉合）と、開口の下端（壁が開口で欠け、開口側の壁は残りが隣接構造に連続するなら端を固定した三辺の骨組）。例：2026-10、地下駅出入口の EVシャフト。
- 四辺閉合の骨組は、剛体変位を止めるだけの**静定支持**（1節点を x、もう1節点を x・y）にする（見本の骨組解析入力と同じ）。全周に一様に載せたケースは支点反力が0になるので、載荷の確かめに使える。片側の土が無いパターンでは支点が側圧の合力を受ける。
- 部材の向き：平面で時計回りに i→j を揃えると、局所 y が全部材で内向きになり、荷重が全部正で書ける。
- **剛域**（【開削標準】第Ⅱ編 7.2、ハンチ無し）：節点から、交わる壁の前面より H/4 内側まで。厚さ H の部材が厚さ T の壁に交わる端の剛域長は **T/2 − H/4**（0以下なら剛域の扱いを見直す）。剛域の断面は A・I を十分大きく（例 1000）する。
- **照査断面**：壁前面（節点から交わる壁の厚さ/2）と、壁前面＋自部材の厚さ/2（h/2 の点）、スパン中央（対称なら両側）。
- コンクリートのヤング係数は【RC標準】の f'ck ごとの表を補間する（f'ck 27 → 26.5 kN/mm²）。

## 載荷パターン

- 隣接構造（通路のボックス・既設躯体など）が接する面は土が無いので、その面には EHP・WHP・GLH のどれも載せない。深さで接する構造が変わるなら計算点ごとに決める。
- 全方向・3方向・2方向のように片側の土が無い場合を組む（偏った側圧で曲げが大きくなる面がある）。開口で壁の無い面のパターンは同じ骨組になるので除く。
- 基本ケースは作用 × パターン（EHP1・WHP1・GLH1 …、数字はパターン番号）。値が0の作用（水位より上の WHP など）のケースは作らない。

## 作用係数と組合せ（例：鉄道の地下駅出入口の設計条件（他工種）6.1 表 地震時以外）

設計条件の表は列が要求性能（○付き数字）、行が作用（D1・D2・EHP…・Wp1〜3・GLH・L・I）。部材（基礎・上床版と下床版・側壁）ごとに列が分かれる。値は案件の表で確かめる。

| 部材 | 要求性能 | 作用係数の例 |
|---|---|---|
| 側壁（⑩〜⑭） | 安全性（破壊） | EHP 1.2・WHP 1.0・GLH 1.2 |
| | 復旧性（損傷）（R5 では使用性（損傷）、下の節） | 1.0・1.0・1.0 |
| | 使用性（外観） | GLH なし 1.0・1.0 と GLH あり 1.0・1.0・1.0 の2つ |
| 上床版・下床版（③〜⑨） | ③④ 安全性（破壊） | D1 1.1・D2 1.2・Wp（高水位）1.0 |
| | ⑤⑥ 安全性（疲労破壊） | 変動作用が無ければ作らない |
| | ⑦⑧ 使用性（外観）・⑨ 復旧性（損傷）（R5 では使用性（損傷）） | D1 1.0・D2 1.0・Wp（低水位）1.0 |

- 抽出ケースは要求性能ごとに全パターンの組合せを包絡する。
- **耐久性（永久作用）を足す**：【RC標準】R5 の耐久性（鋼材腐食）の照査は、永久作用による応力（収縮・クリープを含むひび割れ幅、せん断ひび割れの永久分）と変動作用を分けて使う。設計条件の表に列が無くても、永久作用だけ（EHP 1.0・WHP 1.0、底版なら D1 1.0・D2 1.0・Wp（平水位）1.0）の組合せと抽出を作る。Capacita では行1（永久作用）が無いと耐久性の節が出ない（`structural-capacita`）。
- 地震時の組合せ（表 地震時）は、地震時土圧を考えないなら作らない。

## R5 の要求性能の名前（使用性（損傷）と復旧性（損傷））

- 【RC標準】R5 の安全係数の表（設計条件の例 5.【RC標準 第Ⅲ編 6.2】）は、安全性（構造安全性：破壊・疲労破壊）、**使用性（保守：損傷、外観）**、
  **復旧性（修復性：損傷）**の行に分かれる。例の値：使用性 損傷 γc 1.3・γs 1.0・γb 1.0（曲げ）／1.3・1.0（せん断）・**γi 1.2**、
  外観 すべて 1.0、復旧性 損傷 γc 1.3・γs 1.0・γb 1.0／1.3・1.0・**γi 1.0**。
- H16 の見本や、同じ設計条件の照査フロー（例 8.「耐久性→安全性（破壊）→復旧性（損傷）→構造細目」）は、地震時以外の損傷の照査を
  「復旧性（損傷）」と書く。R5 で照査するなら、地震時以外の損傷は**使用性（損傷）**（Capacita の R5 では行6）、地震時の損傷が
  復旧性（損傷）（行7）。どちらで照査するかで γi が変わる（例 1.2 と 1.0）ので、決めてもらって記録する。
- 判断の例（2026-10-21、地下駅出入口の EVシャフトの側壁・底版）：見本の復旧性（損傷）を使用性（損傷）として照査し（作用係数は表の
  復旧性（損傷）の列のまま、名前を全段階で使用性（損傷）に）、復旧性（損傷）（地震時）は地震時土圧を考えないので照査しない。
  あわせて、使用性（外観）の曲げひび割れを側壁の**内側（常時乾燥の面）だけ**で、最小鉄筋量（R5 は最大鉄筋量も）を
  **耐久性（永久作用）の断面力**で照査した。新しい見出しの条番号は確かめられず、付けずに残した。

## 断面照査の前提（【RC標準】R5）

- **水掛かりの程度**（R5 の耐久性）：常時乾燥・乾湿繰返し・常時湿潤。設計条件の環境条件の例（4.4）：上床版 上面 常時湿潤・下面 常時乾燥、**下床版 上面 常時乾燥・下面 常時湿潤**、側壁 外側（土の側）常時湿潤・内側 常時乾燥。せん断ひび割れは湿潤側（側壁の外側・底版の下面）で照査した例がある。
- H16 の環境条件（一般の環境・腐食性環境・特に厳しい腐食性環境）は R5 では水掛かりの程度に替わり、一対一には対応しない。判断の例（2026-10-21、橋脚の R5 への切替。owner が確認）：一般の環境→常時乾燥、腐食性環境→乾湿繰返し。
- 曲げひび割れ幅の制限値は乾燥 0.005c、乾湿繰返し・湿潤 0.004c（c はかぶり）、鉄筋応力度の制限値 σsl は乾燥・湿潤 140、乾湿繰返し 120 N/mm²（Capacita の実装で確認）。
- 収縮・クリープの ε'csd は【RC標準】解説表7.6.1。設計条件の例（4.5）：自重・材齢30日の行で 常時乾燥 450・乾湿繰返し 250・常時湿潤 100（×10⁻⁶）、k4 0.85。
- 安全係数（γi・γb・γc・γs）は案件の設計条件の表（例：5. 安全係数）から写す。
- 断面力の符号：照査プログラムの上側・下側に外側・内側を対応させ、引張側の欄で確かめる（次の節）。

## 骨組の曲げモーメントの符号と、外側・内側の鉄筋の対応

- 閉合した骨組（立坑・ボックス）に外から一様な側圧が掛かると、**隅角部は外側引張、スパン中央は内側引張**（静力学で決まる。
  全周一様のケースで 隅角部の M ＋ wℓ²/8 ＝ スパン中央の M）。解析結果で、隅角部とスパン中央の M の符号を見て、どちらの符号が
  外側引張かを決める。
- 同じ隅角部の両側の部材で M が同じ符号なら、符号と面の対応は**部材の向き（横向き・縦向き、i→j の向き）によらず全部材で同じ**。
  部材ごとに外側・内側の対応を変える必要はない。
- 対応を決めたら、照査プログラムでは外側の鉄筋・外側の水掛かり（例 常時湿潤）・外側のかぶりを同じ側（上側か下側）にそろえる。
  鉄筋の題だけを変えても、鉄筋量と環境条件は付いてこない。
- 例（2026-10-21、FEMPython の閉合骨組、局所 y を全部材で内向き）：曲げモーメントは**内側引張が正・外側引張が負**だった
  （全周 36.1 kN/m で隅角部 −21.90、スパン中央 +7.45）。前に「外側引張が正」と思い込んで外側の鉄筋を Capacita の下側に置いており、
  照査が外側と内側で入れ違っていた。解析の自動テストが |M| しか見ていなかったので気付かなかった。**符号は隅角部とスパン中央の
  値で確かめ、テストでも符号を見る。**
- 照査プログラムの手入力の修正（例：GUI で鉄筋の題を「外側」「内側」に変えたもの）を受け取ったら、題・鉄筋量・水掛かりが
  同じ面を指しているか、断面力の符号と合うかを確かめてから取り込む。合わなければ根拠を示して確かめてもらう。

## かぶりと配筋

- 標準かぶり（設計条件の例 4.3）：上床版・下床版の上側・下側、側壁の外側・内側とも 50 mm。かぶりは最も外の鉄筋（中間帯鉄筋・スターラップ）までの純かぶり。施工誤差 10 mm を見込む。
- **芯かぶり** = 純かぶり ＋ 帯鉄筋（中間帯鉄筋）の径 ＋ 主鉄筋の径/2、**5 mm 単位で切り上げ**（例 50＋13＋16/2 = 71 → 75）。芯あきも 5 mm 単位で切り上げる。2段目（直交する鉄筋の段）は1段目に接して 1段目の芯＋径/2＋径/2（例 75＋8＋8 = 91。5 mm に切り上げなかった例がある）。
- 鉄筋の例（4.2）：D13〜D32、SD345、主鉄筋・スターラップとも ctc125 を基本。
- 壁・版の中間帯鉄筋は 1 m 幅あたりの本数（例 D13 @250 → 4 本）をスターラップとして照査に入れる。
- 配筋が決まる前に照査するときは仮定の配筋で進め、NG を配筋の見直しに回す（仮定であることを記録する）。
