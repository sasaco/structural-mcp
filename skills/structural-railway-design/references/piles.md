# 場所打ち杭のコンクリート

出典：鉄道構造物等設計標準・同解説 基礎構造物（平成24年版）杭体設計の手引き（以下【杭体手引き】）1.3。表1.3-1 は 2026-10-29 に PDF の頁（Ⅰ-4）を画像で確かめた。

## 施工修正係数 ρc（【杭体手引き】1.3(4)〜(7)、表1.3-1）

泥水中で打ち込むことを考えて、呼び強度から求めた特性値に ρc を掛けて下げる。**工法と泥水比重の管理の条件（区分）が決まれば、係数はすべて決まる**。

| 区分 | 施工法 | 打込み時の泥水比重の管理 | 圧縮・引張・曲げひび割れ・支圧強度 | 付着強度 | ヤング係数 | Vcd の低減係数 |
|---|---|---|---|---|---|---|
| A | オールケーシング工法、自然泥水か CMC 系安定液を用いたリバース工法・アースドリル工法 | 泥水比重 1.04 以下 | 0.8 | 0.7 | 0.8 | 0.9 |
| B | 同上 | 泥水比重の管理を行わない | 0.7 | 0.6 | 0.8 | 0.9 |
| C | ベントナイト系安定液を用いたリバース工法・アースドリル工法 | 泥水比重 1.10 以下 | 0.7 | 0.6 | 0.8 | 0.9 |
| D | 同上 | 泥水比重の管理を行わない | 0.6 | 0.5 | 0.7 | 0.8 |

- 表では B と C の値のセルが結合されている（B と C は同じ値）。
- 補助的にベントナイトを使っても、濃度が 3 % 未満なら自然泥水としてよい（表の注 *1）。
- 設計基準強度 f'ck＝呼び強度 × ρc（圧縮）。ヤング係数は、呼び強度から【RC標準】5.3.1.6(2) で求めた値 × ρc（ヤング係数）。f'ck から引き直さない。
- Vcd（せん断補強鋼材を用いない棒部材）は、ρc で下げた f'cd から【RC標準】式(7.2.4) で求めた値に、さらに低減係数を掛ける（注 *4）。
- 材料強度の設計値は、特性値を【RC標準】の γc で割る（1.3(8)）。
- 呼び強度は 30〜50 N/mm² を標準とする（1.3(1)）。
- 粗骨材の最大寸法は、鉄筋のあきの 1/2 以下かつ 25 mm 以下を標準とする（1.3(3)）。

## 既設の杭で区分が図面に無いとき

古い財産図などには、工法や泥水比重の管理が書かれていないことが多い。区分は**推測で決めず、利用者に決めてもらう**。業務全体で共通にするなら、その案件の前提条件として書く（決めた人と日付も書く）。

- 採用した判断の例（上越新幹線の高架橋、利用者の決定 2026-10-28）：工法が分からない既設の場所打ち杭を、自然泥水のリバース工法かアースドリル工法で、泥水比重の管理をしない **区分 B** とし、業務の前提条件にした。
- 呼び強度は、財産図の材料表にある杭の σ28（kgf/cm²）を 1/10 して N/mm² にした（例：σ28 240 → 24.0。これも業務の前提条件）。

## 杭基礎の照査（地震時以外）の作用の組合せと構造解析係数

出典：鉄道構造物等設計標準・同解説 基礎構造物（平成24年版）（以下【基礎標準】）。2026-10-31 に PDF の頁を画像と文字で確かめた（WebRamen の 0622）。

- **作用の組合せは構造物の種類ごとの例（【基礎標準】解説表5.5-1、印刷 p.84）を先に見る**。解説表15.3.1-1（印刷 p.281）の「長期＝永久作用、短期＝永久作用＋変動作用」は構造物によらない目安で、RC ラーメン高架橋の例とは違う。RC ラーメン高架橋の例：
  - 基礎の安定（地震時以外）：1.1D1＋1.2D2＋[SH＋T]＋1.1L＋1.1I＋1.1C＋(LF)＋(W)＋Wp2 など（[ ] は必要に応じて組み合わせる作用、( ) は従たる変動作用）。
  - 基礎の長期支持性能：D1＋D2＋Wp1（SH を含まない）。
  - 基礎の短期支持性能：D1＋D2＋L＋I＋C＋Wp2（**SH・T を含まない**）。
- **構造解析係数 γa**：地震時以外の安定（安全性）を線形の骨組解析で求めるときは 1.2（【基礎標準】7.3.2 解説「線形モデル…構造解析係数を 1.2 程度とする」、15.2.5 解説「線形解析により設計応答値を算定してもよい。この場合、構造解析係数は 1.2 としてよい」）。使用性（支持性能）は 1.0（15.2.6 解説）。設計応答値（設計鉛直力・水平変位・回転角）＝γa×骨組の値で、照査は γi·Id/ILd ≦ 1.0。
- **着目位置**：剛なフーチングのある群杭はフーチング等の天端の1か所、1柱1杭式のラーメン高架橋は「各杭頭の格点部中心として、各杭ごとに照査するのがよい」（15.3.1 解説、印刷 p.281）。要点は杭ごとに照査すること。骨組では杭頭（地中梁の下端、剛域の端）と地中梁の軸線の節点で水平変位が 10 % ほど違うので、どちらで取ったかを計算書に書く。
- 設計限界値（Rvd・Rud・δL・θL）は SOIL-JR の .sdr の「地震時以外」の段の値をそのまま使える（書式は `structural-jrsnap-soil` の sdr-format）。
