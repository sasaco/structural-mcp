# 静的非線形解析（プッシュオーバー）の照査パターンと Case ごとの照査項目

鉄道の耐震設計で、静的非線形解析（JRSNAP など）の作用の組合せに付ける係数と、その結果の耐震性能照査（Aggre-SE など）でどの Case に何を照査させるかの考え方。道具の使い方はスキル `structural-jrsnap-input`・`structural-jrsnap-ndu`・`structural-aggrese`。

## 係数の意味（JRSNAP Ver5.2-L03 操作説明書で確認）

- **材料修正係数 ρm**：軸方向鉄筋（と PC 鋼材）の強度に掛ける。帯鉄筋・せん断補強鉄筋には掛からない。1.0 と、部材の曲げ耐力を大きめに見る 1.2 を使う。曲げ耐力が大きいほど、せん断破壊の先行（破壊形態）や基礎への作用が厳しくなる。
- **基礎の支持力修正係数 αf**：地盤反力の上限値に掛ける（直接基礎は回転ばねの最大抵抗モーメント Mmd、節点ばね・分布ばねは制限値）。操作説明書の注意事項では「上部構造物を照査する場合は 2.0、基礎構造物を照査する場合は 1.0」、DA カードの説明では「通常は 1.0、基礎構造物が先行降伏する場合の追加検討時は 2.0」。αf＝2.0 の Case は、基礎が先に降伏して上部構造物の応答が小さく出るのを避けるためのもので、基礎の照査には使わない。

## 照査パターンと載荷の向き

- 作用の組合せ（基本ケースの選び方）ごとに、(ρm, αf) の組を変えた Case を作る。(1.0, 1.0)・(1.2, 1.0)・(1.0, 2.0)・(1.2, 2.0) の4つにした例がある（橋脚、2026-10-22）。
- 載荷の向きは正向（増分の作用を地震の向きに）と逆向（反対に）。JRSNAP の逆向は、増分・限定増分の作用と目標変位の符号だけを反転し、固定の作用（死荷重、鉛直の列車荷重など）は変えない。
- 複線の線路直角方向で、上り線・下り線の列車荷重が軸の反対側に載る場合：上り線の組合せを正向、下り線の組合せを逆向で解析すると、偏心が地震の向きと同じ側になる組を両方の線で照査できる（橋脚の例、2026-10-22）。構造が軸について対称なら同じ結果の組になるが、フーチングの偏心などで対称でなければ違う。線路方向（列車荷重が1ケース）は正向だけにした。

## Case ごとの照査項目（Aggre-SE の ①〜⑨ の例）

照査項目は照査パターンで決め、載荷の向きでは変えない。次は採用した例（橋脚、2026-10-22。owner の指定）で、規則として固定されたものではない。

| 照査 | 照査する Case | 考え方 |
|---|---|---|
| ①復旧性 L2・②安全性 L2 | 全 Case | 応答値はどのパターンでも求める |
| ③損傷レベル | (1.0, 2.0) 以外 | |
| ④破壊形態の検討 | ρm 1.2 | 曲げ耐力を大きめに見たときにせん断破壊が先行しないか |
| ⑤せん断耐力 | なし | |
| ⑥L1 地震動 | (1.0, 1.0) | 標準の係数だけ |
| ⑦基礎の安定・⑧杭の段落し・⑨断面力ピックアップ | αf 1.0 | 基礎の照査は αf＝1.0（操作説明書）。ピックアップは基礎・部材の設計に渡す断面力 |

- 地震時の基礎の設計応答値（直接基礎の Rvd到達ステップなど）は、αf＝1.0 の Case から最も厳しいものを採る。αf＝2.0 の Case は使わない。
- 片持ち梁など上部の部材に渡す最大応答震度は、全 Case の最大を採った例がある（安全側）。

## ユーザーに決めてもらうこと

- 照査パターンの組（ρm・αf の値と数）、逆向で解析する組合せ。
- Case ごとの照査項目（上の表は1つの例）。特に ③・⑤ を外すか、⑥ をどのパターンで行うか。
- 基礎や部材の設計応答値をどの Case から採るか（αf＝1.0 だけか、全 Case か）。
