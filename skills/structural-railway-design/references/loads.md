# 作用：側圧・上載荷重・水位・揚圧力・死荷重

## 永久作用としての側圧（【開削標準】第Ⅱ編 5.4.6・5.4.7）

- **砂質土は土水分離**：EHP = K0 × (q + γt·h1 + γ'·h2)、WHP = γw·h2、γ' = γt − γw。h1 は地下水位より上の深さ、h2 は水位から計算点までの深さ、q は地表面の上載荷重（下）。
- **粘性土は土水一体**：EHP = K0 × (q + γt·z)、WHP は載せない。
- 静止土圧係数 K0（【開削標準】第Ⅱ編 5.4.6 の表。鉄道の出入口の設計条件（他工種）3.2 (1) にも同じ表、2026-10 に資料で確認）：

| 土質 | N 値 | K0 |
|---|---|---|
| 粘性土 | 8 ≦ N | 0.5 |
| 粘性土 | 4 ≦ N < 8 | 0.6 |
| 粘性土 | 2 ≦ N < 4 | 0.7 |
| 粘性土 | N < 2 | 0.8 |
| 砂質土 | 50 ≦ N | 0.3 |
| 砂質土 | 30 ≦ N < 50 | 0.4 |
| 砂質土 | N < 30 | 0.5 |

  表には粘性土の硬さ・砂質土の締まりの区分名も並ぶ（呼び名は原文で確かめる）。地層が深さで変わるなら層ごとに γt・K0 を変え、計算点までを足し合わせる。
- 単位体積重量の例（設計条件（他工種）3.4）：鉄筋コンクリート 24.5、水 10.0 kN/m³。土の γt はボーリングの柱状図・土質試験の値を層ごとに。
- **水位ごとに側圧が変わる**。土水分離で K0 < 1 なら、水位が高いほど側圧の合計（EHP＋WHP）が大きい（水位以下では K0·γ' + γw が K0·γt を上回る）。例：γt 15・K0 0.5・q 10・深さ 9.45・水位 GL−1.5 で 36.1＋79.5 = 115.6、水位が計算点より下なら 75.9 kN/m²。作用係数の表は部材・要求性能ごとに使う水位を決めている（例：側壁は高水位だけ、下床版は安全性（破壊）が高水位・使用性と復旧性が低水位の揚圧力）。
- 同じ標高の水位（高水位＝平水位など）は1つのケースにまとめてよい。

## 上載荷重と地表面上の変動作用（GLH）

- **上載荷重（路面交通荷重）**：【開削標準】第Ⅱ編 5.4.2 の解説表5.4.2-1 の路面交通荷重（土被り 4.5m 以上で 10.0 kN/m²）。見本の計算書（EVシャフトの水平断面）は「L：路面荷重 10kN/m²」として EHP の式の q に入れる。図の EHP は地表で K0·q から始まる台形になる。
- **GLH**（【開削標準】第Ⅱ編 5.4.3）：地表面上の変動作用 Pm = 10 kN/m² による土圧 Ph = K0·Pm を全高に一様に載せる。変動作用なので、組合せで作用係数を別に持つ（安全性（破壊）1.2 など）。
- 同じ地表面の荷重を **EHP の q（永久）と GLH（変動）の両方で数えると二重計上**になる。どちらか一方にする、両方載せる（安全側、承知のうえと記録）のいずれも見られるので、設計者・発注者に決めてもらう。両方載せた例：2026-10-21、地下駅出入口の EVシャフト（ユーザーの指示）。
- 舗装の荷重（例 17.1 kN/m²）を側圧に入れるかも判断。入れなかった例がある（上と同じ案件、2026-10-19）。
- 地震時土圧（応答変位法など）を考えるかも判断。考えなかった例がある（同上）。

## 水位と揚圧力（設計条件（他工種）3.2 (2)・3.3）

- 水位は高水位・平水位・低水位の3つ。低水位を底版下面（水が無い）に取る設計条件がある。
- 揚圧力 WVP = γw·(ZB − ZW)（ZB 底面の標高、ZW 水位）。底版では地盤反力度と比べて大きいほうで設計する（`slab.md`）。
- **浮上りの検討だけ高水位＝設計GL** とする設計条件がある（部材の照査の高水位とは別）。

## 死荷重

- D1（固定）：躯体の自重。D2（付加）：上家（地上の建屋）の反力、設備、建築仕上げ（設計条件（他工種）3.4）。
- 上家の反力は建築側から合計で与えられることが多い。支点ごとに分けるか、合計を外寸面積に分布させるかで書き方が変わる。合計 600kN を外寸面積で割った例がある（2026-10-21）。
- EV の設備荷重は機種のカタログ（見本では OTIS の表）から取る。考慮しない判断もある（同上）。

## 開削ボックスの横断方向の応答変位法（線形の骨組）で地震の影響を作る（例：2026-10、JR東海 神奈川県駅の付帯ボックス。発注者の条件書と見本の計算書から）

- 地震の影響は 3 つの基本ケースに分ける：地盤変位（EQG）・周面せん断力（EQS）・慣性力（EQI）。全周に地盤ばね（上下床版 kv・ksv＝kv/3、側壁 kh・ksh＝kh/3）を付けた骨組で解く。向きの逆（←）は線形なので → の係数 −1 で組み合わせる。
- 地盤応答の表（深さごとの絶対応答加速度・変位・せん断応力）は、相対変位が最大の時刻の値か包絡かを確かめる（深部で加速度が負なら時刻の値）。表に無い深さは線形補間。
- 地盤変位：下床版下面の変位を基準にした相対変位 Δu(z) を、**両側壁**に kh·Δu(z)（同じ向き）、上床版に上床版上面の Δu を ksv·Δu としてかける。
- 周面せん断力：上床版上面に τ（運動の向き）、下床版下面に τ（逆向き）、側壁は深さごとの τ を鉛直に（運動の向きの側の壁が上向き、反対側が下向き）。
- 慣性力の設計水平震度：条件書に無ければ、函体の範囲の応答加速度の最大値（相対変位最大時）を g で割り、安全側に切り上げて全部材に一様にかけた例が多い（見本 Kh＝0.25、本例 793 gal→0.81）。かける重量は自重・保護コンクリート・吊り荷重など積載荷重（上載土は含めない）。
- 軸線の外（外面から軸線まで）にかかる分布荷重は隅の節点の集中荷重にする（見本の書き方）。
- 地盤応答から函体の上下面の相対変位が小さいとき、L2 でも損傷レベル1以下とし（復旧性（損傷）を My で照査）、応答が L2 の1組しか与えられなければ L1 を省く判断があった（ユーザーの判断）。
