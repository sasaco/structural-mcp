# 照査の前提（構造細目）と配筋図

断面力によらず、配筋と寸法だけで決まる構造細目の照査と、配筋図の描き方。
出どころは、橋脚の見本の計算書 0400「照査の前提」（H16 系、【RC標準】第Ⅲ編の条を引く）と、別の見本 06（梁・コーベル）。
その一覧を WebPier の 0400 に実装したとき（2026-10-21）に、コードと手計算で確かめた。
条番号は見本の引用のままで、R5 の番号は確かめていない。計算書に書くときは、案件の基準の版で確かめる。

## 断面力によるものとよらないものを分ける

- 断面力を使う照査は、断面照査の節で行う：曲げひび割れ耐力 Mcrd、軸方向力の最大値から定まる最小鉄筋量 0.008Ac、最大鉄筋量 0.75pb、コンクリートの応力度 σc。照査の前提の章には、参照先の節を示す文だけを置く。
  - 見本は、柱下端の N'd を自分で求めて照査している。
  - Capacita の R5 では、行8（最小鉄筋量）の断面力から、これらを1つの節に出す（`structural-capacita` の「R5 の最小鉄筋量と最大鉄筋量」）。
- 0.008Ac の式（見本の値を手計算で再現した。2026-10-21）：Ac＝γi·γb·N'd/(k1·f'cd＋0.008f'yd)、k1＝min(1−0.003f'ck, 0.85)。
  - 例：N'd 7592.8 kN、f'ck 24、SD390、γb 1.3、γi 1.0 → Ac 524690.5 mm²、0.008Ac 4197.5 mm²。

### 梁（張出し）の細目（見本 06 6.3）

- ディープビームの用心鉄筋：各面で断面の 0.08 % 以上、間隔は min(2bw, 300 mm) 以下（【RC標準】13.3.4）。
- コーベルの用心鉄筋：0.40·As 以上、間隔 300 mm 以下。
- 片持ち梁の圧縮鉄筋：引張鉄筋の As/6 以上。

### 採用した判断の例（WebPier 0400、2026-10-21）

- 柱の帯鉄筋の照査は、柱下端を含む配置の行だけで行った。
- 7) ② の 8φ・12φ は、その方向の主鉄筋のうち細いほうの径で求めた（推定）。
- フーチングの鉄筋のあきは、梁と同じ 20 mm・φ にした。見本のフーチングの頁は柱の値（40 mm・1.5φ）を使っていて、これは再現していない。
- 梁の段の芯の間隔が 4/3Dmax に足りない例：梁の上側の段の間のあき 32 mm ＜ 4/3×25 ＝ 33.3 mm（見本の Example2 の配筋）。見本 06 は段の間のあきを照査していないので、この配筋は NG のまま残した。

## 中間帯鉄筋の置き方

- 着目するせん断方向の**有効本数 n**（脚の数）のうち、2本は外巻き帯鉄筋の脚、残りの n−2 本は中間帯鉄筋の脚とする。組数は n/2（中間帯鉄筋の分は (n−2)/2）。
- 中間帯鉄筋は、その方向のせん断に効く脚が並ぶ面の1段目の主鉄筋のうち、面を (n−1) 等分する位置（k·面の長さ/(n−1)、k＝1…n−2）に最も近い主鉄筋に掛ける。
- 7) ③ の 48φ の照査は、外巻きを含む隣り合う脚の最大の間隔で行う。
- 中間帯鉄筋の位置は入力にしない（有効本数と主鉄筋の配置から決まる）。外巻き帯鉄筋の脚を中間帯鉄筋に数えない。
- 組数は、整数なら整数で書く（D22-5組@150）。端数があれば印字桁で書く（3.5組）。

### 既設の配筋図から中間帯鉄筋を読むとき（上越新幹線の高架橋の財産図で分かったこと、2026-10-29）

- 加工図では、外巻きの帯鉄筋と内側の閉じた帯（中間帯鉄筋）が同じ径で並ぶことがある。間隔は、それぞれの**1柱あたりの本数**と柱の高さから確かめる。内側の帯の本数が外巻きの半分なら、帯鉄筋の1段おき（間隔は2倍）に置いた中間帯鉄筋。内側の帯を外巻きと同じ間隔と読むと、有効本数を多く見積もる。
- 内側の閉じた帯は、脚がどちらの方向のせん断に効くかを形（長辺の向き）で分ける。着目する方向に脚が並ばない帯は、その方向の有効本数に数えない。
- 帯鉄筋より粗い間隔の中間帯鉄筋は、**帯鉄筋の間隔に換算した脚数**で有効本数に足す。有効本数＝外巻きの 2脚＋中間帯鉄筋の脚数×（帯鉄筋の間隔／中間帯鉄筋の間隔）。小数になりうる。
- 採用した判断の例（利用者の決定 2026-10-29）：換算した中間帯鉄筋を、θm の帯鉄筋比 pw と Vyd のせん断補強鉄筋の両方に数えた。JRSNAP の NDU では `SectSher` の第3と第9（スキル `structural-jrsnap-ndu`）。拘束にだけ数えてせん断には数えない取り方もありうるので、案件ごとに確かめる。

## 配筋図を ezdxf で描くとき（2026-10-21、ezdxf 1.4.5 で確認）

- 図ごとに縮尺を選ぶ。WebPier では、長辺が紙の上で 120 mm に収まる最小の縮尺を 1/20〜1/500 から選んだ。図の上に「梁（柱前面の断面）　1:25」のような題を置く。
- 日本語：既定の文字スタイルでは PDF の時点で豆腐（□）になる。文字スタイルの font を `msgothic.ttc` にすると、PDF・PNG に日本語が出る。書体のない PC では、ezdxf は黙って別の書体に替える。
- **同じ入力から同じバイト列にする**：
  - DXF：CLASSES 節の並びが PYTHONHASHSEED で入れ替わる（`ClassesSection.add_required_classes` が set を回す。import の順のせいではない）。書く前に、使っている型を名前順に `doc.classes.add_class` して固定する。
  - PDF（`PyMuPdfBackend`）：`get_pdf_bytes()` は毎回ランダムな /ID を書く。`get_replay(...).doc.tobytes(no_new_id=True)` を使う。作成日時は書かれない。
  - PNG：同じ頁の `get_pixmap(dpi=200, alpha=False).tobytes("png")` は決定的。幅は、切り上げで 1 px 増えることがある。
- ezdxf は import のときに home（`Path("~").expanduser()`）を引く。home の決まらない最小の環境（PATH・SystemRoot・TEMP・TMP だけ）の子プロセスでは、RuntimeError で止まる。そのときだけ、USERPROFILE を一時フォルダーの下にしてから import する。
- 計算書に図を入れるときは、ベクターの PDF の頁を form XObject として埋め込む（WebPier は GridLayoutPdf 0.3.0 の `PdfFigure`）。方眼Excel には、同じ頁の PNG を置く。DXF を画像にしてから貼るより、文字と線が崩れない。
