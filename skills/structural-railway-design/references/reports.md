# 計算書の作り方と資料の読み方

## 章立て（鉄道の地下構造物の計算書の見本）

番号付きの冊に分ける見本がある（例：EVピット部）。

| 冊 | 中身 |
|---|---|
| 0300 総括表 | A3 横。部材ごとの照査結果（安全性・使用性/耐久性・復旧性）と検証・変更案 |
| 0410 荷重計算 | 1 構造解析モデル（骨組、計算点、断面諸元、剛域、照査断面）、2.1 作用（水位、側圧 EHP・WHP、GLH） |
| 0420 荷重図・0430 組合せ・0440 断面力図 | 2.2 基本ケースの荷重図、2.3 基本ケース・DEFINE・組合せ・抽出ケース、2.4 断面力図 |
| 0450 配筋・0460 断面照査 | 3.1 部材諸量、3.2 断面力総括、3.3 安全性（曲げ・せん断）、3.4 耐久性（鋼材腐食）、3.5 復旧性（見本、H16 系）。R5 で照査した例（2026-10-21）：3.5 使用性（外観）、3.6 使用性（損傷）、3.7 最小鉄筋量・最大鉄筋量（照査プログラムの頁の順） |
| 05xx 底版・0610 浮上り | 底版の荷重計算・配筋・断面照査（`slab.md`）、浮上りの検討 |

- 照査は【RC標準】【開削標準】【ボックス手引】の条番号を引いて書く。照査プログラムの頁を節ごとに差し込み、計算書の地の文は見出しと前文1文にとどめる見本が多い。
- 骨組解析・断面照査のプログラムの頁は、プログラムの責務の見た目（数値と線の重なりなど）を計算書の側で書き換えない。

## 印字桁と丸め

- **計算書に印刷する値は、その桁に丸めた値を後続の計算に使う**（手計算で追える計算書にするため）。合計も丸めた値の和で書く（例：側圧 36.1＋79.5＝115.6）。四捨五入は ROUND_HALF_UP。
- 桁の例：側圧・部材荷重 kN/m²・kN/m は小数1桁、標高・寸法 m は3桁、底版の荷重・断面力は2桁、係数は3桁（見本どおりに決め、入力より細かい値を受け付けない）。
- 負の値・標高はマイナス記号「−」（U+2212）で書く見本が多い（ハイフンにしない）。

## 見本・発注者の資料の読み方

- 見本の計算書は**体裁と章立て・式の手本**。数値は別構造物なので設計値にしない。式の右辺の数値代入（例「0.5 × (10.0 + 15.0 × 1.500 + 5.0 × 7.950)」）まで見本の書き方に合わせると照合しやすい。
- 設計条件（他工種）など発注者の PDF は、表が `get_text()` で崩れる（作用係数の表など）。pymupdf で頁を PNG にして目で読む（`page.get_pixmap(matrix=pymupdf.Matrix(1.4, 1.4), alpha=False)`）。フォントの埋め込みで文字が取れない PDF も同じ。
- 全頁をざっと見るときは頁ごとに `get_text()` の先頭数百字を UTF-8 で書き出し、当たりを付けた頁だけ PNG にする。
- 元データの Excel：`.xlsx`・`.xlsm` は openpyxl（`data_only=True`）、`.xls` は xlrd 2.0.1。日本語の端末（cp932）で化けないよう、`sys.stdout` を UTF-8 にしてファイルに書き出してから読む。
- DocuWorks（`.xdw`・`.xbd`）は直接読めない。同じ内容の PDF・xls を正とする。
- 図面は DXF（構造のレイヤ）を ezdxf で読んで寸法を測る。3D モデルの DXF（MESH）はレイヤごとの範囲（x・y・z の最小・最大）で隣接構造の位置を確かめられる。

## 作用や配筋を変えたときの照査結果の比べ方

- 作用を変えたら、側圧 → 荷重図 → 組合せ → 断面力 → 照査の全段を作り直す（途中の段だけ直さない）。
- Capacita の照査値と OK/NG は総括表 `summary.xlsx` で比べる（表の並びはスキル `structural-capacita`）。変更前の xlsx を控えてから作り直し、行ごとに NG の数と照査値の最大を比べると、影響を短く報告できる。
- 報告には、変わった代表値（側圧・設計荷重・断面力）の前後と、NG の件数・最大の照査値の前後を書く。
